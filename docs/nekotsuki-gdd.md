## 0. เกมนี้คืออะไร

ผู้เล่นคือ **อาซากิริ โทรุ** นักเรียนปี 2 ที่แค่อยากใช้ชีวิตธรรมดาในเมืองชายทะเลของญี่ปุ่น
แต่รุ่นน้องปี 1 ชื่อ **เนโกโมริ อามาเนะ** ทายาทศาลเจ้าแมว ขี้แยที่สุดในโรงเรียน ดันรักเขาหนักจนน่าสมเพช
อามาเนะร้องไห้ทีไรฝนตกทั้งเมือง และใครก็ตามที่สนิทกับโทรุจะเริ่มเจอเรื่องร้าย
เนื้อเรื่องมีโครงแบบ Yandere Simulator (มีเส้นตายรายสัปดาห์ คู่แข่ง กิจวัตรของนักเรียน และความรักผิดปกติที่สืบทอดในตระกูล)
แต่เล่นจากมุมของคนที่ถูกรัก และทุกอย่างอิงตำนานพื้นบ้านญี่ปุ่นเรื่องแมว

**เสาหลัก 4 ข้อ**
1. **ทำอะไรก็ได้ และทุกอย่างมีผล**: ระบบตา ความจำ ซุบซิบ และผลกระทบแบบ Odd-Space ทั้งชุด ทั้งในโรงเรียนและทั้งเมือง
2. **น้ำตาคืออาวุธ**: อามาเนะไม่ได้ใช้ความรุนแรง แต่ใช้ความรู้สึกผิดของพี่ แรงกดดันของคนรอบข้าง และสภาพอากาศ
3. **ทั้งเมืองคือระบบเดียวกัน**: น้ำตา → ฝน → เศรษฐกิจของเมือง → ท่าทีของคน → ข่าวลือ → น้ำตา
4. **Lore หนัก**: 158 ปี 7 รุ่น มีความลับซ่อนอยู่ทุกชั้น คำถามหลักของเรื่องคือ *ความรักของอามาเนะเป็นของเขาเอง หรือเป็นของแมว?*

## 1. โทนและขอบเขตเนื้อหา

- โรแมนติกคอมเมดี้ที่ค่อย ๆ มืดลง ช่วงต้นตลกและน่ารัก กลางเรื่องเริ่มน่าขนลุก ช่วงท้ายเป็นดราม่าเหนือธรรมชาติ
- ความน่ากลัวมาจากการถูกเฝ้ามอง แรงกดดันทางสังคม และสิ่งที่อธิบายไม่ได้ ไม่มีฉากเลือดสาด
  "อุบัติเหตุ" ทำให้บาดเจ็บหรือหายตัวไปชั่วคราว การต่อสู้ใช้กับภูตในโลกพลบค่ำและนักเลงข้างถนน (ฝ่ายแพ้แค่สลบ)
- ตัวละครหลักเป็นนักเรียนมัธยมปลาย ความรักในเกมจึงไปได้ถึงสารภาพรัก จับมือ ไปเทศกาลด้วยกัน **ไม่มีฉากทางเพศ**
- อามาเนะไม่ทำร้ายตัวเองและไม่ขู่ว่าจะทำร้ายตัวเอง อาวุธของเขามีแค่ร้องไห้ รอ และตามติด เกมนำเสนอว่าความหลงแบบนี้เป็นอันตราย และให้ผู้เล่นได้ทั้งตั้งขอบเขตและช่วยให้เขาโตขึ้น
- IP ใหม่ทั้งหมด ไม่มีชื่อ ตัวละคร ฉาก หรือมุกจาก Yandere Simulator หรือเกมอื่น

## 2. ฉาก: เมืองซุซุนาริ 鈴鳴町

เมืองชายทะเลขนาดเล็กในญี่ปุ่นปัจจุบัน (ปี 2026) ตั้งอยู่ระหว่างเนินเขากับอ่าว มีรถไฟสายเดียววิ่งผ่าน
ชื่อเมืองแปลว่า "เสียงกระดิ่งดัง" เมืองนี้รวยเกินขนาดของตัวเองมาร้อยกว่าปี คนแก่ในเมืองเชื่อว่าเป็นเพราะเทพแมว
รูปปั้นแมวกวักมืออยู่ทุกร้าน และทั้งเมืองมีแมวมากกว่าคน

- **โรงเรียน 私立鈴鳴学園 (Suzunari Gakuen)** โรงเรียนเอกชนบนเนิน มองเห็นทะเล ด้านหลังมีอาคารเรียนไม้หลังเก่า
- **ศาลเจ้าซุซุเนะ 鈴音神社** อยู่บนยอดบันไดหิน 999 ขั้น บนสุดแขวนกระดิ่งใหญ่ที่ตีปีละครั้งในคืนทานาบาตะ
- **ศาลเจ้าอินุไค 犬飼神社** ศาลเจ้าหมาอีกฝั่งของเมือง เป็นคู่ปรับของศาลแมวมาร้อยปี
- ความเชื่อของคนในเมือง: แมวล้างหน้าแล้วฝนจะตก, อย่านับบันไดศาลเจ้าตอนพลบค่ำ, ใครทิ้งคำสัญญาไว้ในเมืองนี้ เมืองจะจำ

## 3. Lore

### 3.1 เส้นเวลา
| ปี | เหตุการณ์ |
|---|---|
| 1868 | **อาซากิริ โซอิจิโร** ลูกพ่อค้าข้าว ออกเดินทางไปโตเกียว สัญญากับแมวจรที่ตัวเองเลี้ยงไว้ (ชื่อ **ซุซุ** เพราะผูกกระดิ่งไว้ที่คอ) ว่าจะกลับมา แล้วไม่ได้กลับมาอีกเลย |
| 1868–1890 | ซุซุนั่งรออยู่ที่บันไดศาลเจ้าทุกวัน ทั้งตอนฝนตกและตอนหิมะตก จนหางแตกเป็นสองแฉก (เนโกะมาตะ) แล้วตายไปในคืนทานาบาตะ |
| 1890 | ชาวเมืองตั้งศาลให้ในชื่อ **ซุซุเนะซามะ 鈴音様** จากนั้นเมืองก็มั่งคั่งขึ้นอย่างแปลก ๆ ตระกูล **เนโกโมริ 猫守** (แปลว่าผู้เฝ้าแมว) รับหน้าที่ดูแลศาล |
| 1890–2001 | ตระกูลเนโกโมริ 5 รุ่น แต่ละรุ่นมีลูก 1 คนที่ "ถูกแมวสิง" ตอนรักครั้งแรก ทุกคนจบไม่เหมือนกัน (ดูบันทึกกระดิ่ง 3.3) |
| 2001 | **เนโกโมริ ซุซุ** (แม่ของอามาเนะ) ถูกสิง และรัก **อาซากิริ มาโคโตะ** (พ่อของโทรุ) คืนทานาบาตะ มาโคโตะหนีออกจากเมือง เขากับ **มาคาเบะ** อยู่ที่บันไดด้วยกันในคืนนั้น |
| 2009 | โทรุเกิดที่โตเกียว |
| 2010 | ซุซุแต่งงานตามที่ครอบครัวจัดให้ และให้กำเนิดอามาเนะ |
| 2011 | คืนทานาบาตะ ซุซุใส่ยูกาตะเดินขึ้นบันไดศาลเจ้า แล้วหายตัวไป (神隠し) พ่อของอามาเนะออกจากเมืองไปหลังจากนั้นไม่นาน อามาเนะโตมากับย่า |
| 2012–2016 | ปู่ของโทรุพาโทรุมาเที่ยวทุกหน้าร้อนลับหลังพ่อ |
| 2016 | โทรุอายุ 7 ขวบ หลงทางบนบันไดในงานเทศกาล และหายไปหนึ่งคืน อามาเนะอายุ 5 ขวบเป็นคนพาเขากลับลงมา โทรุสัญญาว่าหน้าร้อนปีหน้าจะมาอีก หลังจากนั้นพ่อห้ามไม่ให้มาอีก ความทรงจำคืนนั้นของโทรุหายไป |
| 2026 เม.ย. | ปู่ของโทรุเสียชีวิต พินัยกรรมยกบ้านและที่ดินให้โทรุ (ข้ามรุ่นพ่อไป) โดยมีเงื่อนไขว่าต้องอยู่ซุซุนาริจนอายุ 18 โทรุย้ายมาอยู่กับอาสาวที่ร้านขนม ตั้งแต่วันที่เขามาถึง ฝนตกทุกวัน |

### 3.2 กฎของแมวสิง (猫憑き)
- ซุซุเนะซามะไม่ใช่ปีศาจ มันเป็น **การรอคอย** ที่กลายเป็นเทพ สิ่งที่มันต้องการมีอย่างเดียวคือ *ไม่ถูกทิ้งอีก*
- คนที่ถูกสิงจะรักคนแรกที่ตัวเองรักไปจนตาย ยิ่งอีกฝ่ายถอยห่าง ความสิงยิ่งเพิ่ม (憑依度 0–100%)
- สัญญาณที่มองเห็นได้: หูแมว (โผล่เวลาอารมณ์ล้น) → หาง → ตาแมวสีทอง → ลายหนวดสีแดง → เงาบนผนังเป็นรูปแมวสองหาง
- คนธรรมดามองไม่เห็นหูแมว ยกเว้นคนที่ "เคยถูกซ่อน" มาก่อน (โทรุเห็นได้ เพราะเคยหายไปหนึ่งคืนเมื่อ 10 ปีก่อน)
- แมวทั้งเมืองเป็นตาของเทพ แมวที่เห็นอะไรจะไปบอกศาลเจ้า แล้วอามาเนะก็จะ "รู้"
- น้ำตาของคนที่ถูกสิงทำให้ฝนตก (ตามความเชื่อที่ว่าแมวล้างหน้าแล้วฝนจะตก)
- ความสิงทำให้เมืองโชคดี ยิ่งแมวมีความสุข เมืองยิ่งรวย ผู้ใหญ่ในเมืองจึงอยากให้โทรุยอมรับอามาเนะ
- ช่วงพลบค่ำ (逢魔時 18:00–18:30) ถ้าความสิงสูง บันไดจะมี **ขั้นที่ 1000** และขึ้นไปถึงโลกพลบค่ำ (裏鈴鳴) ได้

### 3.3 บันทึกกระดิ่ง 鈴の記録 (ของสะสม lore)
ทุกรุ่นของคนที่ถูกสิงทิ้งบันทึกไว้หนึ่งเล่ม รวม 7 เล่ม กระจายอยู่ในเมือง โรงเรียน คลังเก็บของในบ้านปู่ และโลกพลบค่ำ
แต่ละเล่มเป็นทั้งเรื่องสั้น เบาะแส และวิธีจบที่คนรุ่นก่อนเคยลอง:
1. **ซุซุ (แมว)**: ภาพวาดบนแผ่นไม้ขอพร 1868–1890 รอยเท้าแมวเรียงลงมาตามบันได
2. **เนโกโมริ ฮัตสึ (1912)**: แต่งงานกับคนที่รัก ทั้งคู่มีความสุข แต่สามีไม่เคยออกนอกเมืองได้อีกเลยทั้งชีวิต
3. **เนโกโมริ โทคิจิ (1938)**: คนที่เขารักไปออกรบแล้วไม่กลับ เมืองถูกฝนตกไม่หยุด 40 วัน
4. **เนโกโมริ ยาเอะ (1961)**: พยายามตัดกระดิ่งทิ้ง โชคของเมืองพัง โรงงานปลาปิด เธอใช้ชีวิตที่เหลือกับความรู้สึกผิด
5. **เนโกโมริ ชิโยะ (1979, ย่าของอามาเนะ)**: รักคนที่ไม่รักตอบ เลือกรับแมวไว้แต่ไม่เคยไล่ตามเขา ปัจจุบันเป็นคนเฝ้าศาล และเป็นคนเดียวที่รู้ว่าความสิงกดไว้ได้แต่ไม่หายไป
6. **เนโกโมริ ซุซุ (2001–2011)**: จดหมายถึงมาโคโตะที่ไม่เคยส่ง หน้าสุดท้ายเขียนว่า "ถ้าเขาไม่มา ฉันจะไปหาเขาเอง ที่ที่เราไม่ต้องรออีก"
7. **เนโกโมริ อามาเนะ (2016–ปัจจุบัน)**: สมุดวาดภาพของเด็ก 5 ขวบ ทุกหน้ามีเด็กผู้ชายที่ยืนอยู่บนบันได หน้าหลัง ๆ เป็นรูปถ่ายของโทรุที่แอบถ่ายไว้

### 3.4 ความลับที่เปิดทีละชั้น
1. อามาเนะไม่ได้รักโทรุเพราะเห็นครั้งแรก แต่เพราะ **คำสัญญาเมื่อ 10 ปีก่อน**
2. โทรุ **เคยถูกซ่อน** ไปหนึ่งคืนตอน 7 ขวบ เขาจึงเห็นหูแมวได้ และในคืนนั้นอามาเนะเป็นคนพาเขากลับมา
3. ปู่ของโทรุ **รู้ทุกอย่าง** พินัยกรรมคือความพยายามใช้หนี้ที่ตระกูลอาซากิริค้างไว้ 158 ปี
4. ตระกูลชิราซางิร่ำรวยจากโชคของเทพแมว และ **อยากให้ความสิงอยู่ต่อ** ถึงคนตระกูลเนโกโมริจะต้องทุกข์ก็ตาม
5. ซุซุ (แม่) **ยังไม่ตาย** เธออยู่ในโลกพลบค่ำ นั่งรอที่บันไดเหมือนแมวตัวแรก
6. ครูมาคาเบะ **ก็เคยรักซุซุ** จดหมายในลิ้นชักห้องพักครูเป็นของเขา
7. คำถามสุดท้าย: ถ้าเอาแมวออกจากอามาเนะได้ ความรักยังจะเหลืออยู่ไหม คำตอบขึ้นกับสิ่งที่ผู้เล่นทำมาทั้งเกม

### 5.1 ภูมิหลังของโทรุ (Origin)
ตัวเอกเป็นผู้ชายเสมอ ชื่อเปลี่ยนได้ เลือกแท็ก 5 หมวด (`data/tags.json`) ซึ่งเปลี่ยนบทพูด ค่าเริ่มต้น กริยาที่ใช้ได้ และท่าทีของ NPC
- **ทำไมอยากธรรมดา**: อดีตดาราเด็ก · เคยโดนทัวร์ลงในโซเชียล · อัจฉริยะที่หมดไฟ · ลูกหนี้ · ย้ายโรงเรียนหนีเรื่องบางอย่าง · แค่ขี้เกียจ
- **นิสัย**: ใจดี · ปากร้าย · ไม่สนอะไร · ใจอ่อน (น้ำตามีผลกับเขา x1.5) · เยือกเย็น · ขี้ตกใจ
- **ความสามารถ**: ทำอาหาร · เปียโน · คาราเต้ (ต่อสู้เก่ง) · วาดรูป · เกม · ไม่มีอะไรเลย (ค่าความธรรมดา +)
- **ความลับ**: แพ้ขนแมว (จามทุกครั้งที่อามาเนะหูโผล่) · เห็นผี · มีแฟนอยู่โตเกียว (ทำให้อามาเนะหึงตั้งแต่วันแรก) · ถังแตก · เคยเป็นนักเลง · จริง ๆ แล้วจำได้นิดหนึ่ง
- **เป้าหมายส่วนตัว**: สอบติดมหาวิทยาลัยโตเกียว · ได้แฟนธรรมดา ๆ · เก็บเงินหนีออกจากเมือง · ทำตามพินัยกรรมให้ได้ · ค้นหาว่าปู่ซ่อนอะไรไว้
  (ทำได้ก่อนกำหนดจะมีฉากจบตามเป้าหมาย แบบ motivation endings ของ Odd-Space)

### 5.2 เวลาและตารางชีวิต
- นาฬิกาเดินตลอด 1 วัน: ไปโรงเรียน 07:30 → โฮมรูม → คาบเรียน 1–4 → พักเที่ยง → คาบ 5–6 → ชมรม → ในเมือง → พลบค่ำ 18:00 → กลางคืน (มือถือ, คืนแห่งแมว)
- NPC ทุกตัวมีตารางชีวิต (`data/schedules.json` + สุ่มสำหรับ NPC ทั่วไป) จำได้ ใช้ประโยชน์ได้ และป่วนได้ แบบกิจวัตรนักเรียนใน Yandere Sim
- 1 ภาคเรียน = 13 สัปดาห์ (8 เม.ย. → 7 ก.ค.) มีพิธีเปิดเทอม · โกลเด้นวีค · สอบกลางภาค · ฤดูฝน (梅雨) · กีฬาสี · สอบปลายภาค · คืนทานาบาตะ
- เล่นต่อหลังจบได้ (New Game+ เก็บบันทึกกระดิ่งและนิสัยติดตัวไว้)

### 5.3 สมองของอามาเนะ (`Amane` autoload, `data/amane.json`)
**ค่า**: 恋慕 ความหลง · 涙 น้ำตา (0–5) · 嫉妬 ความหึง (แยกค่าต่อคน) · 安心 ความอุ่นใจ · 自我 ความเป็นตัวของตัวเอง · 憑依度 ความสิง (0–100)

**สัญญาณที่มองเห็น** (ใช้ทั้งในพอร์เทรตและสไปรต์): หูแมวโผล่ เด้ง ลู่ แนบ · หาง · ตาแมว · ลายหนวด · กระดิ่งเงียบ · เงาเป็นแมว · ฝนเหนือหัว

**ระดับน้ำตา**: ปากเบะ → น้ำตาคลอ → ร้องไห้ → โฮ (ฝนตกทั้งเมือง) → พายุ (เหตุการณ์ใหญ่ทั้งโรงเรียน ครูมา)
ยิ่งน้ำตาขึ้น ปุ่มปฏิเสธในบทสนทนายิ่งหดและเบลอ ปุ่มปลอบยิ่งใหญ่ (ใจอ่อนเป็นกลไกจริง)

**พฤติกรรมตามค่า** (แต่ละอย่างเป็น state ของ NPC แบบ Odd-Space):
ตามห่าง ๆ (หลบหลังเสาแต่หูโผล่ ยกกระถางบังหน้า) → รอหน้าห้อง → ฝากข้าวกล่องและจดหมายไว้ในล็อกเกอร์รองเท้า → แชทรัวตอนตีสอง →
รู้ตารางชีวิตของเรา → ไปสืบเรื่องเราจากเพื่อน → จัดการคู่แข่ง → ประกาศผ่านเสียงตามสาย → (ความสิงสูง) ทำสิ่งที่อามาเนะไม่รู้ตัวว่าทำ

**คู่แข่งประจำสัปดาห์**: ทุกวันจันทร์ อามาเนะเลือกคนที่ **สนิทกับโทรุที่สุด** ในสัปดาห์นั้น (คำนวณจากค่าความสัมพันธ์จริง)
คู่แข่งจึงเป็นผลจากการกระทำของผู้เล่นเอง ตัวละครหลักมีเนื้อเรื่องแบบเขียนไว้ ส่วนคนทั่วไปใช้แม่แบบ

**แผนกำจัดคู่แข่ง** (แผนหลายวัน แต่ละขั้นทิ้งเบาะแสไว้ และหยุดได้ทุกขั้น):
1. 泣き落とし ไปร้องไห้ใส่ จนอีกฝ่ายรู้สึกผิดแล้วถอยออกไปเอง
2. 噂 ปล่อยข่าวในเว็บลับ
3. 嫌がらせ แกล้งเล็ก ๆ เช่น เอารองเท้าไปทิ้ง พังล็อกเกอร์ หรือทำข้าวกล่องเลอะ
4. 縁切り พิธีตัดสายสัมพันธ์ที่ศาลเจ้า อีกฝ่ายจะเริ่มหลบโทรุโดยไม่รู้ตัว
5. 罠 ใส่ร้ายว่าโกงสอบหรือขโมยของ จนถูกพักการเรียน
6. 事故 อุบัติเหตุที่แมวเป็นต้นเหตุ ทำให้บาดเจ็บ ต้องนอนโรงพยาบาลหนึ่งสัปดาห์
7. 神隠し (ความสิงมากกว่า 80%) คนนั้นหายตัวไปในโลกพลบค่ำ ถ้าไม่ไปช่วย เขาจะกลับมาโดยลืมโทรุไปหมด

**เส้นตาย**: วันศุกร์ 18:00 (逢魔時) ถ้าไม่มีใครหยุด แผนจะสำเร็จ ชะตาของคู่แข่งแต่ละคนถูกบันทึกและมีผลกับฉากจบ

**วิธีรับมือ**: เตือน เฝ้า สลับตาราง เผชิญหน้ากับอามาเนะ ปลอบเพื่อลดความหึง ตั้งขอบเขต ขอให้แมวเงียบ ฟ้องครู ให้ฮายาเตะ (ศาลหมา) ช่วยกัน หรือพาอามาเนะไปหาเพื่อนใหม่ของเขาเอง
ทางที่ดีที่สุดในระยะยาวคือเพิ่ม **自我** แต่ทำได้เฉพาะตอนที่อามาเนะสงบ

### 5.4 น้ำตา → ฝน → โชคของเมือง (`Weather` autoload)
- ความแรงของฝนในแต่ละวันคำนวณจากน้ำตาของอามาเนะ + ฤดูกาล (ฤดูฝนเดือนมิถุนายนทำให้ทุกอย่างหนักขึ้น)
- ผลของฝน: ร้านในซอยการค้าขายไม่ออก · กิจกรรมกลางแจ้งและชมรมถูกยกเลิก · ร่มที่ร้านสะดวกซื้อขาดตลาด · ชายหาดปิด · NPC อารมณ์เสีย · พื้นลื่น · หิ่งห้อยออกเฉพาะคืนที่ฟ้าใส · ถ้าหยุดร้องหลังจากร้องโฮจะมีรุ้ง (โชคพิเศษ)
- **ดัชนีแมวกวัก 招き猫指数** (−100..100) คือโชคของเมือง มีผลกับราคาของ ลอตเตอรี่ ธุรกิจของตระกูลชิราซางิ ท่าทีของผู้ใหญ่ในเมือง และงบงานเทศกาล
  ในฉากจะเห็นได้จากรูปปั้นแมวกวักตามร้าน ถ้าโชคดีจะยกมือสูง ถ้าโชคร้ายจะเริ่มร้าว
- แอปพยากรณ์อากาศในมือถือจึงเป็นตัวบอกอารมณ์ของอามาเนะไปในตัว

### 5.5 เครือข่ายแมว (`Cats` autoload)
- แมวทุกตัวในเมืองเป็น NPC มีชื่อ (Copy) ความจำ และทัศนคติต่อโทรุ จำได้ว่าใครให้อาหาร ใครลูบหัว ใครไล่
- แมวคือ **พยาน** แบบ Odd-Space แทนที่จะโทรแจ้ง จะเดินกลับไปที่ศาลเจ้า (มีแถบแสดงความคืบหน้าเหนือหัว) ถ้าไปถึง อามาเนะจะรู้เรื่องนั้น
  ("พี่ไปกินราเมงกับพี่ฮายาเตะมาใช่ไหม... แมวบอก")
- หยุดแมวได้โดยให้ปลาแห้ง (煮干し) ลูบหัว อุ้มไปที่อื่น หรือทำให้แมวชอบเรามากพอ แมวที่ชอบเรามาก ๆ จะไม่ไปฟ้อง หรือบางทีก็โกหกแทนเรา
- ถ้าทำร้ายแมว ทั้งเมืองจะรู้ทันที (ชาวเมืองเห็นแมวเป็นของศักดิ์สิทธิ์)

### 5.6 ข่าวลือ เว็บลับ และการกระทำผิด (`Causality`)
- การกระทำที่มีคนเห็นจะเข้าสู่ระบบพยานแบบ Odd-Space ถ้าเป็นเรื่องร้ายแรง (โดดเรียน ลอกข้อสอบ ต่อยกัน ขโมย ปีนรั้ว) จะมีคนไปฟ้องครูหรือคณะกรรมการระเบียบ
- เรื่องอื่น ๆ จะกลายเป็นข่าวลือ ไปโผล่เป็นกระทู้ใน **เว็บลับของโรงเรียน** (Copy grammar) และกระจายไปตามเครือข่ายเพื่อน
- ชื่อเสียงมีหลายแกน เช่น คนทำน้องร้องไห้ · คู่จิ้น · ตัวซวย (คนรอบตัวเจอเรื่องร้าย) · คนดี · นักเลง · คนโปร่งใส
- ชมรมหนังสือพิมพ์ (ฮินะ) ช่วยลบหรือเบี่ยงข่าวได้ ส่วนสภานักเรียน (เรย์จิ) สืบเรื่องอุบัติเหตุ และจะหันมาสงสัยโทรุถ้าหลักฐานชี้มาทางเขา

### 5.7 ทำอะไรก็ได้ (Interactions)

### 5.8 มือถือ
- **Rinrin** (แอปแชท): อามาเนะส่งมาไม่หยุด ข้อความแต่งจาก Copy grammar ตามค่าของเขา การอ่านแล้วไม่ตอบ ตอบช้า ปิดแจ้งเตือน หรือบล็อก มีผลกับวันรุ่งขึ้นทั้งหมด
- **เว็บลับ** (裏サイト): ข่าวลือเกี่ยวกับเรา อ่าน โพสต์ หรือปล่อยข่าวเองก็ได้
- **กล้อง**: รูปเป็นหลักฐานได้ และแลกข้อมูลกับมิโอะได้ (ผนังห้องของอามาเนะเต็มไปด้วยรูปแอบถ่ายของโทรุ ถ้าถ่ายรูปผนังนั้นได้ จะเป็นหลักฐานชิ้นสำคัญ)
- แผนที่ · พยากรณ์อากาศ (บอกอารมณ์อามาเนะ) · ตารางงานพิเศษ · โน้ต

### 5.9 กระดานสืบสวน
ผนังห้องในบ้านปู่มีกระดานไม้ก๊อก เบาะแสที่เจอถูกปักไว้อัตโนมัติ ลากด้ายแดงเชื่อมเบาะแสเพื่อสรุป (`data/clues.json` ใช้ grammar เงื่อนไขเดียวกับ Odd-Space)

### 5.12 ฝ่ายในเมือง (ชื่อเสียง −100..100)

### 5.13 ค่าสถานะ เงิน ชมรม งานพิเศษ นิสัยติดตัว
- ค่าสถานะ: การเรียน · พลังกาย · เสน่ห์ · ความกล้า · ความคล่อง + **ความธรรมดา (平凡度)** ซึ่งเป็นเป้าหมายของโทรุ
- ชมรม: เคนโด้ (ต่อสู้เก่งขึ้น) · กรีฑา · ดนตรี · ทำอาหาร (ทำข้าวกล่องได้) · ไสยศาสตร์ (เข้าถึง lore) · หนังสือพิมพ์ (คุมข่าว) · สภานักเรียน · ชมรมกลับบ้าน (ความธรรมดาขึ้นเร็วสุด)
- งานพิเศษ: ร้านสะดวกซื้อ · คาเฟ่ · ร้านขนมของอา · ตลาดปลา · ผู้ช่วยที่ศาลเจ้า (ได้อยู่ใกล้อามาเนะ)
- สอบกลางภาคและปลายภาค: อ่านหนังสือ ติว หรือลอก (ถ้ามีคนเห็นจะโดนเรียกพบ)
- นิสัยติดตัว: ทำอะไรซ้ำ ๆ จะกลายเป็นนิสัย เช่น ใจอ่อน (ปลอบอามาเนะ 10 ครั้ง) · หนีเก่ง · ทาสแมว · คนโปร่งใส (คนเริ่มลืมว่ามีเราอยู่)
- เพื่อนที่เดินตาม (สูงสุด 2 คน): ฮายาเตะ (ให้ค่าความภักดี) · ฮินะ (ความจริง) · มิโอะ (ความอยากรู้) · เรย์จิ (กฎระเบียบ)
  ถ้าไม่พอใจจะเดินออก ไปปล่อยข่าว หรือแอบไปร่วมมือกับอามาเนะ

## 7. ฉากจบ (ประกอบจากหลายแกน)

แกนที่ใช้: สิ่งที่เลือกในคืนสุดท้าย × ความสิง/ความเป็นตัวของตัวเองของอามาเนะ × ความธรรมดาของโทรุ × โชคของเมือง × ชะตาของคู่แข่ง × บันทึกกระดิ่งที่เก็บได้ × ความทรงจำปี 2016
ตอนจบจะมีการ์ดบอกชะตาของตัวละครทุกตัว (แบบ composed endings ของ Odd-Space)

**ทางเลือกในคืนทานาบาตะ**: ตีระฆังด้วยกัน · รักษาสัญญา ("ฉันกลับมาแล้ว") · ตัดกระดิ่งทิ้ง · หนีออกจากเมือง · เข้าไปในโลกพลบค่ำ · รับแมวมาไว้ในตัวเอง

ตัวอย่างฉากจบ:
1. **普通の日々 วันธรรมดา** (จบจริง): จำได้ เก็บบันทึกครบ อามาเนะเป็นตัวของตัวเองสูง และรักษาสัญญา หูแมวหายไป อามาเนะยังขี้แยเหมือนเดิมแต่ฝนไม่ตกแล้ว ทั้งคู่เดินไปโรงเรียนด้วยกันแบบคนธรรมดา (ความสัมพันธ์จะเป็นแบบไหน ผู้เล่นเลือกเอง)
2. **鈴の契り สัญญากระดิ่ง**: ตีระฆังตอนที่ความสิงสูง ผูกกันตลอดไป ฉากสุดท้ายมีแมวทั้งเมืองนั่งมอง และกระดิ่งดังทุกก้าวที่โทรุเดิน
3. **待ち猫 แมวที่รอ**: หนีออกจากเมือง หลายปีต่อมาอามาเนะยังนั่งอยู่บนบันได เมืองมีฝนตกตลอดไป
4. **晴れ ฟ้าใส**: ตัดกระดิ่งทิ้ง คำสาปหาย แต่โชคของเมืองพัง ทั้งเมืองโทษสองคนนี้
5. **逢魔の祭 เทศกาลไม่รู้จบ**: ทั้งคู่อยู่ในโลกพลบค่ำตลอดไป
6. **母の帰還 แม่กลับบ้าน**: พาซุซุกลับมาได้ ความสิงย้ายไปอยู่ที่แม่ ซึ่งยังรอมาโคโตะอยู่
7. **入れ替わり สลับที่**: โทรุรับแมวมาไว้ในตัวเอง อามาเนะเป็นอิสระ ภาพสุดท้ายคือโทรุที่มีหูแมว ยิ้มอยู่ "คราวนี้ฉันจะเป็นฝ่ายรอเอง"
8. **犬と猫 หมากับแมว**: จับมือกับศาลเจ้าหมา ฮายาเตะปกป้องโทรุไว้ได้ อามาเนะถูกผนึก
9. **生徒会 สภานักเรียนชนะ**: เรย์จิเปิดโปงอามาเนะ อามาเนะถูกไล่ออก ความสิงคุมไม่อยู่ เมืองน้ำท่วม
10. **透明人間 คนโปร่งใส**: ความธรรมดาเต็ม เทพแมวทำให้คำขอเป็นจริงตามตัวอักษร ไม่มีใครในเมืองจำโทรุได้อีก
11. **炎上 ไวรัล**: เรื่องในเว็บลับหลุดออกไปทั้งประเทศ ทีวีมาถ่ายทำ ชีวิตธรรมดาจบลงตรงนั้น
12. **先生の手紙 จดหมายของครู**: ส่งจดหมายของมาคาเบะให้ถึงมือ ครูเดินเข้าไปในโลกพลบค่ำเพื่อพาซุซุกลับมาแทนโทรุ
13. **家族 ครอบครัว**: พ่อกลับมาขอโทษที่บันได คำสัญญาปี 2001 ถูกชดใช้แทน คำสาปอ่อนลง
14. **ふたりきり เหลือกันสองคน**: คู่แข่งหายไปหมดทุกคน ทั้งเมืองเหลือแค่โทรุกับอามาเนะ
15. **正しい距離 ระยะที่พอดี**: ตั้งขอบเขตมาตลอด ไม่ได้คบกัน อามาเนะมีเพื่อนและชมรมของตัวเอง หูแมวจะโผล่เฉพาะวันที่โทรุไปไหว้ศาลเจ้าตอนปีใหม่
16. **猫の町 เมืองแมว**: แมวรักโทรุที่สุดในเมือง เขากลายเป็นทายาทของศาลเจ้าแทน
17. **神隠し ถูกซ่อน**: โทรุเองหายไป (ฉากจบร้าย)
18. ฉากจบตามเป้าหมาย: ถ้าทำเป้าหมายส่วนตัวสำเร็จก่อนกำหนด จะจบเร็ว เช่น ย้ายโรงเรียนหนีไปได้ หรือสอบติดโตเกียว

ใช้ `tools/count_endings.gd` นับจำนวนฉากจบที่เป็นไปได้ทั้งหมดได้เหมือน Odd-Space

## 8. แผนที่ (LevelBuilder ASCII → 3D, ฉากเดินต่อกันได้ทั้งเมือง)

**โรงเรียนซุซุนาริ**: ประตูกับทางลาดซากุระ · ล็อกเกอร์รองเท้า (จดหมายรักและข้าวกล่องโผล่ที่นี่) · ห้องพักครู · ห้องพยาบาล · ร้านค้าในโรงเรียน · โรงอาหาร

· อาคารเรียนไม้หลังเก่า (ชมรมไสยศาสตร์ ทางเข้าโลกพลบค่ำ) · โรงยิม · สระว่ายน้ำ · ลู่วิ่ง · หลังโรงเรียนที่แมวมารวมกัน · ที่จอดจักรยาน

**ตัวเมือง**
- หน้าสถานี: ทางรถไฟตัดถนน (เสียงกระดิ่งเตือนกลมกลืนกับเสียงกระดิ่งของอามาเนะ) · ป้ายรถเมล์ · บ่อแช่เท้า

## 9. ภาพและเสียง

**ภาพ (HD-2D แบบ Odd-Space ทุกอย่าง)**
- ตัวละครสไปรต์ 64×64 จาก `sprite_forge.py` (palette-indexed, 5 ทิศ) เพิ่มชิ้นส่วนใหม่: หูแมว (เด้ง/ลู่/แนบ) · หาง · ฮู้ด · เบลเซอร์ · ชุดกะลาสี · ชุดพละ · ยูกาตะ · ร่ม · แมว (หลายทรงและหลายลาย)
  ท่าใหม่: หลบหลังเสา · ยกกระถางบังหน้า · ร้องไห้ · ถือร่ม · นั่งยอง ๆ ให้อาหารแมว · ปีนกำแพง (แมว)
- พอร์เทรตตอนคุยกัน 64×64 จาก `tools/portrait_forge.py` (แบบในหน้าตัวอย่าง): วาดชิ้นส่วนเป็นเวกเตอร์ แปลงเป็นพิกเซลที่ขนาดจริง แบ่งผมเป็นกระจุก ลงเงา ใส่เส้นขอบแบบ sel-out แล้ววางตาและปากเป็นพิกเซลที่วาดเองทีละจุด
  อามาเนะมีสีหน้าอย่างน้อย 12 แบบ ตัวละครหลักคนละ 4–6 แบบ ส่วน NPC ทั่วไปสุ่มทรงผม สีผม ตา และชุด
- ฉาก: ตึกและพร็อพ low-poly ใช้ texture พิกเซลพร้อม normal map (`gen_textures.py`) ได้แก่ ไม้ญี่ปุ่น กระเบื้อง กระดานดำ ประตูบานเลื่อน ตู้กดน้ำ เสาไฟฟ้าสายระโยง ทางรถไฟตัดถนน หินบันได โทริอิ โคมไฟ
- แสงตามช่วงเวลา: เช้าฟ้าทอง · กลางวัน · พลบค่ำสีส้มทอง · 逢魔時 สีแดงเข้ม · กลางคืนสีคราม ที่มีแสงตู้กดน้ำกับร้านสะดวกซื้อ
- ฤดูกาล: ซากุระ → ต้นหน้าร้อน → ฤดูฝน (ดอกไฮเดรนเยีย) → หน้าร้อน (หิ่งห้อย เสียงจักจั่น โคมไฟเทศกาล)
- ฝน: ถนนเปียกสะท้อนแสง (`_glow_spots` ของ Odd-Space) แอ่งน้ำกระเพื่อม NPC กางร่ม ความแรงของฝนเปลี่ยนตามน้ำตา
- ภาพเด่นประจำเกม: เมฆฝนเหนือหัวอามาเนะ · หูแมวโผล่จากหลังเสา · เงาบนผนังเป็นแมวสองหางเวลาความสิงสูง (ใช้แสงและเงาจริงของ HD-2D) · บันไดที่มีขั้นงอกขึ้นมาเองตอนพลบค่ำ
- กล้องและ post เหมือน Odd-Space (CameraRig, `hd2d_post.gdshader`, tilt-shift, bloom) และใช้ข้อควรระวังเดียวกัน (มุมกล้อง 30° มองเห็นแค่ระดับถนน ของ "ว้าว" ต้องอยู่ที่ระดับสายตา)

**เสียง** (`gen_audio.py`)
- ดนตรี: lo-fi/city pop ผสมโคโตะและชามิเซ็น (Karplus-Strong) เพลงแยกตามสถานที่และช่วงเวลา และเพลงงานเทศกาลที่มีไทโกะ
- ฝนมีหลายชั้นตามความแรง · เสียงจักจั่น · เสียงทางรถไฟตัดถนน · เสียงคลื่น
- **กระดิ่งของอามาเนะ** เป็นเสียงตามตำแหน่ง ได้ยินก่อนเห็นตัว (ใช้เป็นสัญญาณตอนย่อง) และถ้ากระดิ่งเงียบไปแปลว่ากำลังจะเกิดเรื่อง

## 10. สถาปัตยกรรมและข้อมูล

`EventBus` → `DataDB` → `Game` → `Clock`(ใหม่) → `Factions` → `Causality` → `Origin` → `Friends`(=Crew) → `Habits`(=FlawPerk) →
`Weather`(ใหม่) → `Cats`(ใหม่) → `Amane`(ใหม่) → `Saga` → `Stories` → `Interactions` → `Phone`(ใหม่) → `Clues`(ใหม่) → `Twilight`(ใหม่) → `Audio` → `Router`

ระบบที่ต้องเก็บสถานะต้องมี `reset()/to_save()/from_save()` และลงทะเบียนใน `Game._systems()` เหมือนเดิม

ข้อมูล (`data/`): `tags.json` · `schedules.json` · `amane.json` (ค่า สัญญาณ แผนกำจัดคู่แข่ง ขั้นของแผน เบาะแส) · `rivals.json` · `cats.json` · `weather.json` ·

`barks.json` · `copy*.json` · `enemies.json` · `weapons.json` · `tips.json` · `maps/*.txt`

เทสต์ (headless แบบ Odd-Space, ผลลัพธ์คือ exit code):
`check_project.gd` · `smoke_test.gd` (เล่นสุ่ม 13 สัปดาห์ หลายชีวิตจนถึงฉากจบ) · `amane_test.gd` (แผนทุกแบบ × ทุกขั้น × ทุกวิธีหยุด) · `cats_test.gd` · `weather_test.gd` ·
