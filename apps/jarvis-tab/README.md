# Jarvis Tab — ผู้ช่วย AI ส่วนตัวบน Galaxy Tab S12 Ultra

ผู้ช่วยสั่งด้วยเสียง พูด "Hey Jarvis" แล้วค้นข้อมูลจากเว็บจริง ตอบพร้อมที่มา แสดงเป็นหลายแผงบนจอเดียวแบบ HUD ทั้งข้อความ ตัวเลข กราฟ ภาพ และคลิป

**ดาวน์โหลด:** https://teelopnee.github.io/More-co./jarvis-tab/ (เปิดบนแท็บเล็ต แล้วทำตามขั้นตอนในหน้านั้น)

โปรเจกต์ Android อยู่ใน `android/` · `npm test` ตรวจสัญญาระหว่างหน้าดาวน์โหลดกับโปรเจกต์ ·
`npm run build` = ทดสอบ `:core` (รวมคำปลุกด้วยไฟล์เสียงจริง) → `assembleRelease` → `dist/jarvis-tab.apk` + หน้าดาวน์โหลด
(ต้องมี Java 17+ และ `ANDROID_HOME`; GitHub Actions มีให้แล้ว · `JARVIS_GRADLE=/path/to/gradle` ใช้ Gradle ที่มีอยู่)
กุญแจเซ็นใช้ secret เดียวกับแปะไว้ notch (`PAEWAI_KEYSTORE_B64`, `PAEWAI_KEYSTORE_PASSWORD`) ไม่มี = รุ่นทดลองที่เซ็นด้วยกุญแจ debug

## เวอร์ชัน 0.3: เรียกด้วยเสียงได้เลย ไม่ต้องแตะ

**พูดว่า "Hey Jarvis"** → ลูกแก้ววาบแสง → Jarvis ทักทาย ("ครับ ผมฟังอยู่") → ฟังคำสั่งภาษาไทย → ค้นแล้วจอค่อย ๆ เต็มไปด้วยแผง → อ่านสรุปให้ฟัง

- **ฟังคำปลุกในเครื่องทั้งหมด** ใช้โมเดล openWakeWord "hey jarvis" ผ่าน ONNX Runtime ไม่มีเสียงออกนอกเครื่อง ไม่ต้องมีคีย์
  ทดสอบกับเสียงสังเคราะห์ 4 เสียง: ปลุกครบทุกเสียง, ไม่ปลุกกับ "Hey Travis"/"Hey Charles"/ประโยคทั่วไป/เสียงรบกวน 30 วินาที,
  ผลตรงกับ openWakeWord ต้นฉบับ (ต่างไม่เกิน 0.007), ใช้เวลา ~2.5 ms ต่อเสียง 80 ms
- **กันปลุกมั่ว:** ต้องได้คะแนนสูงติดกัน 2 ช่วง (160 ms) และพัก 2 วินาทีหลังปลุก ปรับความไวได้ในหน้าตั้งค่า
- **ไมค์ไม่แย่งกัน:** ระหว่างทักทาย/ฟังคำสั่ง ระบบคำปลุกหยุดไมค์ชั่วคราวแล้วกลับมาฟังเอง ไมค์หลุดก็เปิดใหม่เอง
- **ใช้แอปอื่นอยู่ก็เรียกได้** (เปิด "ฟังต่อแม้สลับไปแอปอื่น" + อนุญาต "แสดงทับแอปอื่น") แอปจะเด้งขึ้นมา จอดับอยู่ก็เปิดจอให้
- **คำสั่งเสียงที่ทำทันที** (ไม่ส่งให้ AI): "หยุด", "เคลียร์จอ", "เริ่มใหม่", "ปิดเสียง"/"เปิดเสียง", "พูดอีกที",
  **"อธิบายให้ฟัง" / "walk me through it"** = อ่านทีละแผง พร้อมไฮไลต์แผงที่กำลังพูดถึงเป็นกรอบชมพู
- ถามเรื่องใหม่ระหว่างที่กำลังค้นเรื่องเดิม → หยุดเรื่องเดิมแล้วทำเรื่องใหม่

**ข้อมูลหลายแบบในจอเดียว (แบบในคลิปอ้างอิง):**

- `VIDEO //` คลิป YouTube/TikTok เล่นในแผง (ปิดเสียง วนซ้ำ) แตะ ↗ เพื่อเปิดในแอป — หาคลิปผ่าน Tavily (`find_videos`) ไม่ต้องมีคีย์ YouTube
- `IMAGE //` ภาพประกอบจากการค้น (Tavily include_images) และภาพปกข่าว
- `STAT //` ตัวเลขสำคัญตัวโต เช่น `≈20M` — ต้องมีที่มาเสมอ ไม่มีที่มาแอปตัดทิ้ง
- `DATA //` กราฟแท่งสีขาวจากตัวเลขในที่มา (ตรวจว่าจำนวนป้าย = จำนวนค่า และมีที่มาจริง)
- `TEXT //` บทวิเคราะห์แยกเป็นการ์ดละหัวข้อ เนื้อหายาวแบ่งหน้า ◂ ▸
- จอกว้าง: การ์ดข้อความ/ตัวเลข/กราฟอยู่ซ้าย คลิปและภาพเรียงซ้อนทางขวา
- ระหว่างค้น แผงทยอยขึ้นสด ๆ: `RESEARCH // ACTIVE` (BLOCKS · SOURCES · STEPS), `INCOMING //` ที่มาล่าสุด, คลิปและภาพที่เพิ่งเจอ

**ความเสถียรที่เพิ่มในรุ่นนี้:** จัดหน้าคำตอบพังได้ลองใหม่แค่ 1 ครั้ง (เดิมเรียกโมเดลซ้ำได้ถึง 10 ครั้ง),
หลังอ่านเนื้อหาจากเว็บแล้วโมเดลสั่งเปิดแอป/ลิงก์/ตั้งปลุกไม่ได้ (กันข้อความในเว็บสั่งเครื่อง),
ตัวแปลงเสียงไม่ตอบใน 20 วินาทีตัดเอง, TTS พังก็ทำขั้นถัดไปต่อได้

### ตั้งค่าครั้งแรกบนแท็บเล็ต (สำหรับคำปลุก)

1. เปิดแอป → อนุญาต **ไมโครโฟน** และ **การแจ้งเตือน** (การแจ้งเตือน "Jarvis พร้อมฟัง" ต้องมีตลอดที่ฟังอยู่ เป็นกติกาของ Android)
2. ถ้าอยากเรียกได้ตอนใช้แอปอื่น: ตั้งค่า → เปิด "ฟังต่อแม้สลับไปแอปอื่น" → กด **อนุญาต** ที่ "เด้งขึ้นมาเหนือแอปอื่น"
3. Samsung ชอบปิดแอปเบื้องหลัง: กด **อนุญาต** ที่ "ไม่ให้ระบบปิด Jarvis" และเพิ่ม Jarvis ใน
   ตั้งค่า → การดูแลแบตเตอรี่ → ขีดจำกัดการใช้งานเบื้องหลัง → **แอปที่ไม่เข้าสู่โหมดสลีป**
4. ถ้าเปิด "Hi Bixby" (ปลุก Bixby ด้วยเสียง) ไว้ บางช่วงไมค์อาจถูก Bixby ใช้ แถบบนจะขึ้น `MIC IN USE BY ANOTHER APP`
5. คำปลุกเป็นภาษาอังกฤษ "Hey Jarvis" (โมเดลสำเร็จรูป) ส่วนคำสั่งหลังจากนั้นพูดไทยได้ตามปกติ

## หน้าตา (เวอร์ชัน 0.2): จอ HUD ไซไฟ

- **ลูกแก้วสีชมพูกลางจอ** คือตัวผู้ช่วย แตะเพื่อพูด (หรือ `Ctrl+J`) สถานะเปลี่ยนตามที่ทำ: ว่าง = กากบาทเล็งเป้า, ฟัง = วงกระเพื่อมตามเสียง, ค้น = แสงวิ่งรอบวง, พูด = ชื่ออยู่กลางวง เปิดแอปครั้งแรกมีฉากวงแหวนเอียงหมุนก่อนเข้าลูกแก้ว
- **พอเริ่มค้น ลูกแก้วย่อไปมุมขวาล่าง** แล้วแผง `RESEARCH // ACTIVE` ขึ้นมา (ชื่อเรื่อง ขั้นตอนที่กำลังทำ แถบความคืบหน้าแบบแบ่งช่อง จับเวลา) จากนั้นแผงคำตอบโผล่ทีละใบเป็นโมเสกกรอบฟ้า มีเลขลำดับ `01/07` ที่หัวแผง
- **ภาพข่าวเป็นแผงเต็มใบ** (`IMAGE // ชื่อเว็บ`) เมื่อข่าวนั้นมีรูปปก
- **ปุ่มมุมขวาบน** `HISTORY` `NEW` `CLEAR VIEW` `SETTINGS` (CLEAR VIEW เคลียร์จอให้โล่งโดยไม่ลบประวัติ)
- **มุมซ้ายล่าง** มิเตอร์เสียงจากไมค์ + ปุ่ม `MUTE` ปิดเสียงอ่านคำตอบ
- ตัวอักษรเป็น JetBrains Mono (ลิขสิทธิ์ OFL ดู `android/third_party/`) ภาษาไทยใช้ฟอนต์ไทยของเครื่อง

## ทำอะไรได้ (เวอร์ชัน 0.1)

- **สั่งด้วยเสียงภาษาไทย** — กดลูกแก้วไมค์ หรือกด `Ctrl+J` ระบบจะอ่านคำตอบออกเสียงเมื่อถามด้วยเสียง มีโหมดสนทนาที่อ่านจบแล้วฟังต่ออัตโนมัติ
- **ค้นข้อมูลจริง พร้อมที่มา** — ค้นเว็บและข่าว ดึงราคาหุ้นและกราฟจาก API ทุกข้อความมีเลขอ้างอิง `[3]` ที่กดเปิดแหล่งได้
- **หน้าจอหลายแผงแบบแดชบอร์ด** — มีแผงภาพรวม, กราฟ, ราคาล่าสุด, ข่าว (มีรูป), ปัจจัยที่ส่งผล, บทวิเคราะห์, คำแนะนำ และที่มา
- **ถามต่อได้ ข้อมูลเดิมไม่หาย** — คำตอบเก่ายังอยู่บนจอ บนจอกว้างระบบจะปักกราฟหรือภาพรวมของคำถามก่อนไว้ที่แผงด้านข้างให้อัตโนมัติ
- **คลิกไปดูเอง** — ข่าวและที่มาเปิดในแผงด้านข้างของแอป หรือกดเปิดเป็นหน้าต่างใหม่ใน DeX
- **คำสั่งอุปกรณ์ที่เสถียร** — เปิดแอป, เปิดลิงก์, ตั้งเวลา, ตั้งปลุก และเพิ่มนัดในปฏิทิน (ระบบเปิดหน้ายืนยันให้กดเอง)
- **จำเซสชัน** — ประวัติคำถาม คำตอบ และกราฟเก็บไว้ในเครื่อง เปิดย้อนดูได้

## ตัวอย่าง: "วิเคราะห์ตลาดหุ้นเทควันนี้ให้หน่อย"

1. ผู้ช่วยวางแผนการค้น แล้วเรียกเครื่องมือหลายตัวพร้อมกัน: ค้นข่าววันนี้, ดึงราคา QQQ/XLK/SMH/NVDA…, ดึงข่าวตลาด และดึงกราฟ
2. บนจอจะเห็นขั้นตอนที่กำลังทำแบบสด ๆ
3. ได้แผงคำตอบ ตัวเลขราคาและกราฟมาจาก API โดยตรง ไม่ได้ให้ AI แต่งขึ้นเอง
4. ถามต่อได้ เช่น "แล้ว NVDA ล่ะ ทำไมลง" ระบบจะใช้ที่มาเดิมต่อ และค้นเพิ่มเฉพาะส่วนที่ใหม่

## ใช้ฟรี 100% ได้ไหม

ได้ ทุกส่วนมีแผนฟรีที่ไม่ต้องผูกบัตร (ตัวเลขจากหน้าเอกสารของแต่ละเจ้า ณ พ.ย. 2026):

| ส่วน | ฟรีอย่างไร | ขีดจำกัด |
|---|---|---|
| คำปลุก "Hey Jarvis" | ทำงานในเครื่อง | ไม่จำกัด |
| แปลงเสียงเป็นข้อความ / อ่านออกเสียง | บริการของเครื่อง (Google/Samsung) | ไม่จำกัด |
| สมอง: **Gemini** (ค่าเริ่มต้น) | คีย์ฟรีจาก Google AI Studio | จำกัดครั้งต่อนาที/ต่อวันตามรุ่น (ดูใน AI Studio) · แผนฟรีอาจนำข้อความไปใช้ปรับปรุงบริการของ Google |
| สมองสำรอง: OpenRouter รุ่น `:free` | คีย์ฟรี | 20 ครั้ง/นาที, 50 ครั้ง/วัน (เคยเติม 10 ดอลลาร์ = 1,000/วัน) — 1 คำถามใช้ 2–5 ครั้ง |
| ค้นเว็บ + หาคลิป: Tavily | 1,000 เครดิต/เดือน ไม่ต้องใช้บัตร | ~1 เครดิตต่อการค้น 1 ครั้ง (1 คำถามใช้ราว 2–5) |
| ราคาหุ้น + ข่าว: Finnhub | แผนฟรีสำหรับใช้ส่วนตัว | ~60 ครั้ง/นาที |
| กราฟราคา: Twelve Data | แผน Basic ฟรี | 8 ครั้ง/นาที, 800 ครั้ง/วัน |
| คลิป YouTube/TikTok ในแผง | ฝังเล่นแบบปกติ | ไม่ต้องมีคีย์ |

รุ่นของ Gemini ไม่ได้ฝังไว้ในแอป: เว้นช่อง "รุ่น" ว่าง แอปจะดึงรายชื่อจาก Google แล้วเลือก Flash ล่าสุดเอง
(กด "ดูรุ่นที่ใช้ได้" เพื่อเลือกเองก็ได้) · OpenRouter กด "ดูโมเดลฟรี" ได้รายชื่อรุ่น `:free` ที่ใช้เครื่องมือได้ ณ ตอนนั้น ·
ถ้าผู้ให้บริการไม่รับการบังคับเรียกเครื่องมือ แอปลดระดับเอง (ระบุชื่อ → required → auto) แล้วจำไว้

**ทดสอบกับ Gemini ฟรีของจริงแล้ว (18 พ.ย. 2026):** ช่วงที่คนใช้เยอะ รุ่น Flash ตอบ 503 "high demand" หรือ 429 พร้อมกันทั้งตระกูล
แอปจึงเรียงรุ่นสำรองจากรายชื่อสดแบบสลับ Flash กับ Flash-Lite, ข้ามรุ่นที่ไม่ว่าง/ถูกปิด (404) ไป 10 นาที, ไม่รอรุ่นไหนเกิน 60 วินาที
และส่ง `thought_signature` ของ Gemini 3 กลับไปตามที่ API บังคับ — ผล: ถามเรื่องตลาด VR ได้คำตอบเต็ม (ตัวเลข, บทวิเคราะห์, คลิป, กราฟ)
ในราว 16 วินาที และ "ตั้งเวลา 25 นาที" ใน 8 วินาที · ทดสอบซ้ำได้ด้วย
`JARVIS_LIVE_GEMINI=1 GEMINI_API_KEY=… ./gradlew :core:test --tests '*LiveGeminiTest*'` (ใน `android/`)

## ติดตั้งบนแท็บเล็ต

3. อนุญาตไมโครโฟนและการแจ้งเตือน แล้วพูด "Hey Jarvis" ได้เลย

**ภาษาไทยสำหรับเสียง:** ถ้ารับเสียงไทยไม่ได้ ให้ไปที่ **ตั้งค่า → การจัดการทั่วไป → การตั้งค่าแป้นพิมพ์/การแปลงเสียงเป็นข้อความ** แล้วตั้งบริการเป็น Google และดาวน์โหลดภาษาไทย ส่วนการอ่านออกเสียงให้ตั้ง **Text-to-speech** เป็น Google และเลือกภาษาไทย

**เรียกด้วยปุ่มด้านข้าง:** ตั้ง Jarvis เป็นแอปผู้ช่วยที่ **ตั้งค่า → แอป → เลือกแอปเริ่มต้น → แอปผู้ช่วยดิจิทัล** (แอปรองรับ ASSIST แล้ว) หรือตั้งให้ปุ่มด้านข้างกดสองครั้งเพื่อเปิด Jarvis ก็ได้ เมื่อเปิดด้วย ASSIST แอปจะเริ่มฟังทันที

## โครงสร้างโปรเจกต์

```
android/
├── core/   ← "สมอง" Kotlin ล้วน ไม่ผูกกับ Android (ใช้ซ้ำกับเวอร์ชัน PC ได้)
│   ├── agent/      Agent (วงจรคิด→ใช้เครื่องมือ→สรุป), Prompts, ทะเบียนที่มา
│   ├── llm/        ไคลเอนต์ OpenAI-compatible (OpenRouter) + tool calling
│   ├── tools/      web_search, read_page, get_quotes, get_price_history, get_market_news
│   ├── providers/  Tavily, Finnhub, Twelve Data, ตัวอ่านหน้าเว็บ
│   ├── market/     แคชราคา/กราฟ, สถานะตลาดสหรัฐฯ
│   └── model/      Briefing (โครงคำตอบหลายแผง), Session, Source
└── app/    ← แอป Android (Jetpack Compose)
    ├── voice/      SpeechInput (เสียง→ข้อความ), Speaker (อ่านออกเสียง)
    ├── device/     เปิดแอป/ลิงก์, ตั้งเวลา/ปลุก, เพิ่มนัด
    ├── data/       การตั้งค่า (คีย์เข้ารหัส Keystore), เก็บเซสชัน
    └── ui/         หน้าจอหลัก, Reactor (ลูกแก้ว), Components (กรอบ HUD), แผงคำตอบ, กราฟ, แผงด้านข้าง (WebView), ตั้งค่า
```

### ทำไมถึงเสถียรและเชื่อถือได้

- **ตัวเลขไม่ได้มาจาก AI:** โมเดลเลือกแค่ว่าจะแสดงหุ้นตัวไหน ช่วงเวลาไหน ส่วนตัวเลขราคาและกราฟ แอปดึงจาก API เองทั้งหมด ถ้าโมเดลขอกราฟตัวที่ยังไม่ได้ดึง แอปก็ดึงให้เองก่อนแสดง
- **ตัดที่มาปลอมทิ้ง:** เลขอ้างอิงที่ไม่ได้มาจากผลค้นจริงจะถูกลบก่อนแสดงผล
- **ทนต่อ JSON เพี้ยน:** โมเดลส่งรูปแบบผิดเล็กน้อยก็ยังอ่านได้ (ทดสอบแล้วในโมดูล core)
- **เครือข่ายสะดุด:** มีการลองใหม่อัตโนมัติ, timeout ต่อเครื่องมือ, จำกัดความถี่ให้อยู่ในโควตาฟรี และแคชผลไว้
- **ข้อความในเว็บเป็นแค่ข้อมูล:** prompt สั่งให้ไม่ทำตามคำสั่งที่ซ่อนอยู่ในเว็บหรือข่าว และคำสั่งอุปกรณ์จำกัดไว้เฉพาะงานปลอดภัย ไม่มีการส่งข้อความหรือจ่ายเงิน
- **หมุนจอหรือย่อหน้าต่าง DeX ไม่ทำให้ข้อมูลหาย:** สถานะเก็บใน ViewModel และบันทึกลงไฟล์

## เปลี่ยนโมเดล

ในหน้าตั้งค่า เปลี่ยน **Model** เป็นรุ่นใดก็ได้บน OpenRouter ที่รองรับ tool calling ถ้าจะใช้ผู้ให้บริการอื่นที่รองรับรูปแบบ OpenAI (`/chat/completions`) ให้เปลี่ยน **Base URL**

## แผนต่อไป

1. **คุมหน้าจอแทนผู้ใช้ (Accessibility Service):** ใช้กับแอปที่ไม่มีช่องทางสั่งตรง มีการยืนยันก่อนทำทุกครั้ง และมี allow-list ว่าแตะแอปไหนได้บ้าง
2. ~~คำปลุก "Jarvis"~~ ทำแล้วในรุ่น 0.3 (openWakeWord) — ถ้าอยากได้คำปลุกภาษาไทย ต้องเทรนโมเดลเพิ่ม
3. **แสดงคำตอบแบบ streaming** ให้ตัวหนังสือค่อย ๆ ขึ้นระหว่างสรุป
4. **เวอร์ชัน PC:** ใช้ `:core` ตัวเดิม แล้วทำหน้าจอด้วย Compose Multiplatform (Desktop)
5. หุ้นไทย (SET) — ต้องหาแหล่งข้อมูลที่รองรับก่อน

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| "คีย์ API ของ … ไม่ถูกต้อง" | ตรวจคีย์ในหน้าตั้งค่า (ระวังเว้นวรรคหน้า/หลัง) |
| ไม่มีกราฟ | ใส่ Twelve Data key ถ้าขอหลายตัวพร้อมกันอาจต้องรอประมาณ 1 นาที (โควตาฟรี 8/นาที) |
| ราคา "ไม่พบสัญลักษณ์" | Finnhub ฟรีรองรับหุ้นและ ETF สหรัฐฯ เท่านั้น |
| รับเสียงไม่ได้ | ดูหัวข้อ "ภาษาไทยสำหรับเสียง" ด้านบน |
| เปิดข่าวบางเว็บไม่ขึ้น | กดปุ่ม "เปิดในหน้าต่างใหม่" เพื่อเปิดในเบราว์เซอร์ |

| ตื่นเองบ่อย | ลดความไวในตั้งค่า (เลื่อนไปทาง "เข้มงวด") |
| เรียกตอนใช้แอปอื่นแล้วแค่มีแจ้งเตือน | อนุญาต "เด้งขึ้นมาเหนือแอปอื่น" ในหน้าตั้งค่า |
| คลิปบางคลิปเล่นในแผงไม่ได้ | เจ้าของคลิปปิดการฝัง — แตะ ↗ เปิดในแอป YouTube |

## ทดสอบ

```bash
cd android
./gradlew :core:test     # ทดสอบสมอง (Agent + เครื่องมือ + ตรวจที่มา) โดยไม่ต้องมีคีย์จริง
```

`android/core/src/test/.../AgentFlowTest.kt` เล่นวงจรจริงทั้งรอบด้วยคำตอบสำเร็จรูปแทนอินเทอร์เน็ต ครอบคลุม: เรียกเครื่องมือพร้อมกัน, ตัดที่มาปลอม, ดึงกราฟ/ราคาที่โมเดลลืมให้เอง, ถามต่อด้วยที่มาเดิม, ไม่มีคีย์, คีย์ผิด

`android/core/src/test/.../WakeWordTest.kt` ป้อนไฟล์เสียงจริง (`android/core/src/test/resources/wake/`, สังเคราะห์ด้วย Piper 4 เสียง) เข้าระบบคำปลุก
เทียบผลกับ openWakeWord ต้นฉบับ (`reference_scores.json`) และตรวจว่าไม่ปลุกกับคำอื่น/เสียงรบกวน · `VoiceCommandsTest`, `VideoRefTest` ทดสอบคำสั่งเสียงและการอ่านลิงก์คลิป
