# แปะไว้ — แปะทุกเรื่องที่ค้างในหัว

นึกอะไรออกก็แปะไว้ก่อน แล้วกลับไปทำงานต่อ อัดเสียงแล้วถอดความ สรุป และทำมายด์แมปได้ เปิดจากขอบจอแท็บเล็ต Samsung เป็นหน้าต่างลอยได้ ใช้บนมือถือและ iPhone ก็ได้ ซิงก์ข้ามเครื่องผ่าน GitHub ส่วนตัว และให้ Claude ช่วยคิดต่อได้

**เปิดใช้:** https://teelopnee.github.io/More-co./paewai/

ได้แรงบันดาลใจจากแอปจดที่อยู่ในรอยบาก (notch) ของ MacBook บนแท็บเล็ต Samsung ไม่มีรอยบาก
จึงใช้ **Edge panel + หน้าต่างลอย (Pop-up view)** แทน: ปัดขอบจอ ลากแอปออกมา พิมพ์ กด Enter แล้วย่อเป็นไอคอนลอยไว้ข้างจอ

## ตั้งบนแท็บเล็ต Samsung (ครั้งเดียว)

1. เปิดลิงก์ด้านบนใน Chrome → ⋮ → **เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป**
   (Samsung Internet: ≡ → **เพิ่มหน้าลงใน** → **หน้าจอหลัก**)
2. การตั้งค่า → หน้าจอ → **Edge panels** → เปิด → แผง **แอป** → แก้ไข → เพิ่ม **แปะไว้**
3. ปัดแถบที่ขอบจอ แล้ว **ลาก** ไอคอน แปะไว้ ออกมากลางจอ = หน้าต่างลอย (ลากจาก Taskbar ก็ได้)
4. แตะแถบบนของหน้าต่างลอย → **ย่อ** = ไอคอนกลมลอยข้างจอ แตะเมื่อไหร่ก็พร้อมพิมพ์
5. กดค้างที่ไอคอนแอป มีทางลัด *แปะเรื่องใหม่ / โน้ตวันนี้ / โฟกัส 25 นาที*
6. แชร์ข้อความหรือลิงก์จากแอปไหนก็ได้ → **แปะไว้** = เข้ากล่องรับ

ชื่อเมนูอาจต่างกันเล็กน้อยตามรุ่น One UI ถ้าลากแล้วไม่เป็นหน้าต่างลอย ให้เปิด
การตั้งค่า → ฟีเจอร์ขั้นสูง → Labs → *Multi window for all apps* (ในแอปมีคู่มือนี้ที่เมนู ⋯ ด้วย)

## iPhone (เช่น 14 Pro Max)

1. เปิดลิงก์ใน **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** → เปิดจากไอคอน (เต็มจอ ใช้ออฟไลน์ได้)
2. ⋮ → **ซิงก์ข้ามเครื่อง** → วางโค้ดจากแท็บเล็ต (แท็บเล็ต: ⋮ → ซิงก์ข้ามเครื่อง → เชื่อมเครื่องอื่น มีทั้ง QR และโค้ด)
3. **เคาะหลังเครื่อง 2 ครั้ง = พูดแล้วแปะ** โดยไม่ต้องเปิดแอป: ทำคำสั่งลัด (Shortcuts) ตามขั้นตอนใน ⋮ → ซิงก์ข้ามเครื่อง → *คำสั่งลัด iPhone*
   แล้วตั้งที่ การตั้งค่า → การช่วยการเข้าถึง → สัมผัส → แตะด้านหลัง เรียกด้วย Siri หรือปุ่มบนหน้าจอล็อกก็ได้

iPhone ไม่ให้แอปบนเว็บวางอะไรไว้ที่ Dynamic Island และไม่ให้ตั้งเตือนตอนปิดแอป
เตือนตรงเวลาแม้ปิดแอปให้ใช้ “ลงปฏิทิน” (ปฏิทิน iPhone เตือนให้) ถ้าอยากได้แถบที่ Dynamic Island จริง ๆ ต้องเป็นแอป iOS (Swift + Live Activities) ซึ่งต้องใช้ Mac/Xcode และบัญชี Apple Developer

## ซิงก์ข้ามเครื่อง

ข้อมูลเก็บเป็นไฟล์ `paewai.json` ใน repo **ส่วนตัว** บน GitHub ของเจ้าของเอง (เช่น `paewai-data`) แอปคุยกับ api.github.com ตรง ๆ ไม่มีเซิร์ฟเวอร์ตัวกลาง

- ตั้งครั้งแรก (~2 นาที): ⋮ → ซิงก์ข้ามเครื่อง → ปุ่ม *สร้าง repo* (Private) → ปุ่ม *สร้างโทเคน*
  (fine-grained token: เลือกเฉพาะ repo นั้น, Contents: Read and write) → ใส่ชื่อ repo กับโทเคน → เชื่อมต่อ
- เครื่องอื่น: สแกน QR หรือวางโค้ดจาก *เชื่อมเครื่องอื่น* แอปจะถามก่อนเชื่อมทุกครั้ง
- ซิงก์เองทุกครั้งที่แก้ (รอ ~2 วินาทีรวบเป็นครั้งเดียว) ทุกนาทีที่เปิดอยู่ และตอนกลับมาที่แอป ใช้ออฟไลน์ได้ ต่อเน็ตแล้วรวมให้เอง
- แก้พร้อมกันหลายเครื่องไม่หาย: รายการไหนแก้ล่าสุดชนะ ลบแล้วไม่ฟื้น บันทึกประจำวันเทียบเป็นวัน
- โทเคนเก็บในเครื่องนั้นเท่านั้น ไม่อยู่ในไฟล์สำรอง และ repo ต้องเป็น Private (แอปไม่ยอมเชื่อม repo สาธารณะ)
- **inbox**: ไฟล์ข้อความในโฟลเดอร์ `inbox/` ของ repo (หนึ่งบรรทัดหนึ่งเรื่อง) จะถูกจัดเข้าที่ตอนซิงก์แล้วลบทิ้ง
  ใช้กับคำสั่งลัด iPhone และให้ Claude เพิ่มเรื่องได้ · `CLAUDE.md` ใน repo อธิบายรูปแบบข้อมูลให้ Claude

## โน้ตแบบการ์ด (แนบรูปได้)

หน้า **โน้ต** มีกระดานการ์ดแบบ Google Keep แตะ *จดโน้ต…* หรือพิมพ์ในช่องแปะ (`โน้ต: ไอเดียคลิป #งาน` ใส่ป้ายกำกับให้เอง)

- **ชื่อเรื่อง + เนื้อหา** บันทึกเองระหว่างพิมพ์และตอนปิด โน้ตว่างไม่ถูกเก็บ
- **รูปภาพ**: เลือกจากเครื่อง (หลายรูป) ถ่ายรูป วางจากคลิปบอร์ด ลากมาวาง หรือแชร์รูปจากแอปอื่นเข้าแอป Android
  รูปถูกย่อไม่เกิน 1600 px เก็บในเครื่อง (IndexedDB) และซิงก์ไปที่ `media/` ใน repo ของคุณ เครื่องอื่นจึงเห็นรูปด้วย
  แตะรูปเพื่อดูเต็มจอ ปัดไปรูปถัดไป ซูมด้วยสองนิ้วหรือแตะสองครั้ง บันทึกลงเครื่อง หรือวาดทับ
- **วาดเขียน** ด้วยนิ้ว เมาส์ หรือ S Pen (หนักเบาตามแรงกด ฝ่ามือไม่รบกวน): ปากกา ปากกาเน้นข้อความ ยางลบ 6 สี 3 ขนาด เลิกทำ/ทำอีกครั้ง
- **รายการติ๊ก**: Enter ขึ้นข้อใหม่ ติ๊กบนการ์ดได้โดยไม่ต้องเปิด ข้อที่ติ๊กแล้วลงไปอยู่ล่าง
- **สี 10 สี · ป้ายกำกับ · ปักหมุด · เก็บถาวร · ถังขยะ** (เก็บไว้ 7 วัน กู้คืนได้) กรองด้วยแถบชิปเหนือกระดาน
- ⋮ ในโน้ต: คัดลอก แชร์ ทำสำเนา **สรุปโน้ต (ในเครื่อง ไม่ใช้ AI)** ทำมายด์แมป ย้ายไปเป็นงาน
- แถบ *ทั้งหมด · โน้ต · เสียง · มายด์แมป · ประจำวัน* เลือกดูทีละส่วน · ไฟล์สำรองมีรูปของโน้ตอยู่ด้วย

## ถาม Claude

⋮ → **ถาม Claude** (หรือแตะงาน → *ให้ Claude ช่วยแตกเป็นขั้น ๆ*) มีคำถามสำเร็จรูป: จัดตารางวันนี้ สรุปสัปดาห์ ดูรายจ่าย ของที่ควรซื้อเพิ่ม
ไม่ต้องมี API key: ใช้กับแอป Claude หรือ claude.ai ตามแพ็กเกจที่มี ด้วยการคัดลอกและวาง

1. **คัดลอกแล้วเปิด Claude**: แอปเรียบเรียง prompt ให้ครบ (ข้อมูลในแอป → คำถาม → วิธีตอบ) วางในแชตใหม่แล้วส่ง
   แตะ *ดูข้อความที่จะส่ง* เพื่อดูก่อนว่าส่งอะไรไปบ้าง ปิด *ส่งงาน โน้ต และรายจ่ายให้ Claude ดูด้วย* ได้
2. **วางคำตอบกลับมา**: กดปุ่มคัดลอกใต้คำตอบของ Claude แล้ววางในข้อ 2 (หรือในช่องแปะหน้าแรกก็ได้)
   Claude ถูกขอให้ปิดท้ายด้วยกล่อง `แปะไว้` บรรทัดละเรื่อง (`งาน: 14/11 09:00 …` `ซื้อ: …` `โน้ต: …` `จ่าย: …` วันที่เป็น วว/ดด ไม่ใช้ “พรุ่งนี้”)
   แอปแยกรายการให้ติ๊กเลือกแล้ว *แปะที่เลือก* ถ้าไม่มีกล่องนี้ จะเสนอบรรทัดในรายการของคำตอบให้เลือกเอง
   ในแอป Android กลับจาก Claude แล้วคำตอบจะถูกวางให้เอง

- ถ้าใส่ API key ของตัวเอง (ไม่จำเป็น · console.anthropic.com คิดตามการใช้) จะมีปุ่ม **ถามในแอป (API)** เพิ่ม
  ค่าเริ่มต้นคือ Claude Opus 5.5 เปลี่ยนเป็น Sonnet 5.5 / Haiku 5.5 ได้ คีย์เก็บในเครื่องนั้นเท่านั้น
- Claude Code ที่เปิด repo ข้อมูลอ่านไฟล์และวางเรื่องใหม่ใน `inbox/` ได้ (“สรุปงานสัปดาห์นี้”, “เพิ่มนัดหมอพรุ่งนี้ 10 โมง”)

## อัดเสียง ถอดความ สรุป มายด์แมป

โน้ต → **อัดเสียง** (หรือ ⋮ → อัดเสียง, กดค้างไอคอนแอป → อัดเสียง)

- หน้าอัดแบบแอปอัดเสียงของเครื่อง: เวลา คลื่นเสียง พัก/อัดต่อ หยุด **ปักหมุด** ช่วงสำคัญ (แตะ 📍 ระหว่างอัด หรือปุ่ม *ปักหมุด* ในการแจ้งเตือนของแอป Android) · หน้าจอเปิดค้างไว้ระหว่างอัด
- **ไม่หาย**: เสียงถูกบันทึกลงเครื่องทุก 4 วินาที ปิดแท็บหรือแอปค้างกลางคัน เปิดใหม่จะกู้คืนให้ · อัดยาว ๆ แบ่งไฟล์ทุก 25 นาทีให้เอง
- **อัดได้นานหลายชั่วโมง** ไม่มีการตั้งเวลาตัด (ราว 22–29 MB ต่อชั่วโมง) ในแอป Android:
  - ปิดจอได้ (foreground service + wake lock) · มีสายเข้า/วิดีโอคอล จะพักเองแล้วอัดต่อเมื่อวางสาย
  - ไม่เริ่มอัดถ้าที่ว่างต่ำกว่า 50 MB และหยุดพร้อมบันทึกเมื่อเหลือไม่ถึง 20 MB
  - ตั้งค่า → *อัดยาว ๆ ตอนปิดจอ* บอกที่ว่าง (อัดได้อีกกี่ชั่วโมง) และปุ่มขอยกเว้นจากการประหยัดแบต สำหรับ Samsung ให้เพิ่มแปะไว้ใน *Never sleeping apps* ด้วย
  - ถ้าการถอดสดสะดุดกลางทาง จะถอดช่วงที่ขาดจากไฟล์ต่อให้เองหลังหยุดอัด (การถอดหยุดเฉพาะเมื่อผิดพลาด 8 ครั้งติดกันโดยไม่ได้ยินอะไรเลย)
  - ถอดไฟล์ที่บันทึกไว้ทำงานต่อได้แม้ปิดแอป มีความคืบหน้าเป็นเปอร์เซ็นต์ในการแจ้งเตือนและหน้าแอป
- ข้อความถอดเสียงเก็บได้ราว 20 ชั่วโมงต่อบันทึก ถ้าที่เก็บของเบราว์เซอร์ (localStorage ~5 MB) เต็ม ข้อมูลทั้งหมดย้ายไป IndexedDB ให้เอง ไม่หาย
- **หน้าดูบันทึก**: แตะหมุดเพื่อเล่นจากตรงนั้น ปักหมุดเพิ่มระหว่างฟัง · แตะในข้อความแล้ว *เล่นจากตรงนี้* (รู้ว่าแต่ละช่วงพูดตอนไหน) · ⋮ → *ส่งออกเป็นไฟล์ข้อความ* ได้สรุป หมุด และข้อความพร้อมเวลา
- **ถอดเสียงด้วยระบบของเครื่อง** (ค่าเริ่มต้น ไม่ต้องใช้คีย์ ไม่ใช้ AI อื่น):
  - แอป Android: ระบบรู้จำเสียงของแท็บเล็ต (ตัวเดียวกับพิมพ์ด้วยเสียงของ Samsung/Google) ถอดไปพร้อมกับที่อัด ข้อความขึ้นสดบนหน้าอัด พร้อมตอนกดหยุด
    ถ้าดาวน์โหลดภาษาไทยลงเครื่องแล้ว เสียงไม่ออกนอกเครื่องเลย (ตั้งค่า → ถอดเสียงเป็นข้อความ บอกสถานะและมีปุ่มดาวน์โหลด)
  - เบราว์เซอร์ (Chrome / Safari): ถอดสดระหว่างอัดด้วยระบบของเบราว์เซอร์ ถ้ามันแย่งไมโครโฟน แอปจะปิดการถอดสดเองและอัดต่อ
  - อัดด้วยแอปบันทึกเสียงของ Samsung ก็ได้: แชร์ไฟล์เสียงมาที่แปะไว้ (แอป Android ถอดให้) หรือแชร์ข้อความถอดเสียงของ Samsung มา ข้อความยาวจะเก็บเป็นบันทึกพร้อมสรุป
  - ไม่บังคับ: ถอดไฟล์ด้วยคีย์ Google Gemini (`gemini-3.8-flash`) หรือ OpenAI (`gpt-transcribe`) ที่ ⋮ → ถาม Claude → ตั้งค่า
- **จัดวรรคตอนให้เป็นภาษาไทย** (`src/lib/thai.js`): ตัวถอดเสียงของเครื่องมักใส่ช่องว่างหลังทุกคำ ("วัน นี้ เรา จะ คุย")
  แอปต่อคำกลับ แล้วเว้นวรรคเฉพาะตรงที่หยุดพูดจริง หลัง "ครับ/ค่ะ" และก่อนคำขึ้นประโยค เวลาของแต่ละช่วงยังชี้ถูกที่
  บันทึกเก่าถูกแก้ให้เองตอนเปิด (เลิกทำได้) หรือสั่งเองที่ ⋮ → *จัดวรรคตอนใหม่*
- **AI ช่วยเกลาและสรุป (ไม่จำเป็น ปิดไว้ก่อน)** (`src/lib/ai.js`): ใส่คีย์ Google Gemini หรือ OpenRouter ของตัวเองที่ตั้งค่า แล้วจะมีปุ่ม
  *เกลาข้อความด้วย AI* (แก้คำที่ถอดผิดจากบริบท ไม่ย่อ ไม่ตัด ส่งทีละช่วง คงเวลาไว้) และ *สรุปด้วย AI* (สรุป มายด์แมป สิ่งที่ต้องทำ)
  ข้อความถูกส่งออกเฉพาะตอนกดปุ่ม · รุ่นของ OpenRouter อ่านจากรายการปัจจุบันบนเครื่อง
- **สรุปในเครื่อง ไม่ใช้ AI** (`src/lib/summarize.js`): ได้ข้อความแล้วสรุปให้ทันที ข้อความไม่ออกนอกเครื่อง
  - รู้ว่าเป็น **ประชุม / บรรยาย / สัมภาษณ์-สนทนา / โน้ตเสียง** แล้วจัดสรุปแบบนั้น (อย่างเทมเพลตของ Notta / Otter): บรรทัด **สรุปสั้น** ด้านบน (เรื่องอะไร กี่หัวข้อ ตกลงกี่เรื่อง งานกี่อย่าง ค้างอะไร) แล้วแต่ละหัวข้อพร้อม **เวลา** แตะ [2:15] ฟังตรงนั้นได้
  - บรรยาย: **นิยาม** (“X คือ …”), **ข้อดี/ข้อเสีย**, **ข้อแนะนำ** (ควร/ไม่ควร/แนะนำ), การบ้าน · สัมภาษณ์: **ถาม–ตอบ** ทีละข้อ
  - แยก **หัวข้อที่คุย** ตามที่ผู้พูดบอก (“เรื่องต่อไปคือ…”, “สุดท้ายเรื่อง…”) หรือดูจากคำที่เปลี่ยนไป (TextTiling)
  - เลือกประโยคสำคัญของแต่ละหัวข้อด้วย TextRank + คำสำคัญที่พูดซ้ำ ไม่เอาประโยคที่ซ้ำกัน (MMR) และตัดคำฟุ่มเฟือย (เอ่อ, ครับ/ค่ะ, “เขาบอกว่า”)
  - **ข้อสรุป** (“ตกลง…”, “สรุปว่า…”), **ต้องทำ** พร้อมคนรับผิดชอบและวันเวลา (“คุณบีช่วยทำแผนงบส่งภายในศุกร์นี้” → คุณบี · ศ. 13 พ.ย.), **ยังไม่สรุป** (คำถามที่ยังไม่มีคำตอบ, “ยังไม่ได้ตัดสินใจ”), **ตัวเลขสำคัญ**
  - คำตอบสั้น ๆ ได้ใจความจากคำถามก่อนหน้า (“งบทั้งทริปเท่าไหร่” + “ไม่เกิน 15,000 บาทต่อคน”), ตัวเลขที่พูดเป็นคำกลายเป็นตัวเลข (“สองสัปดาห์” → 2 สัปดาห์), วันที่ย่อ (15 ธ.ค.)
  - ข้อความจากระบบถอดเสียงที่ไม่มีเว้นวรรค หรือแบบมี “ผู้พูด 1 (00:00)” ของ Samsung ก็อ่านได้ · ข้อความราว 950 ประโยค (ประชุมราวหนึ่งชั่วโมง) ใช้เวลาไม่ถึงครึ่งวินาทีบนเครื่องทดสอบ
  - สิ่งที่ต้องทำแปะลงงานพร้อมวันเวลาได้ในแตะเดียว · ชื่อบันทึกเปลี่ยนเป็นหัวข้อที่คุยให้เอง
- **มายด์แมปในเครื่อง**: เปิดแท็บมายด์แมปแล้วได้เลย หัวข้อกลาง กิ่งละหัวข้อที่คุย (ไม่เกิน 7±2 กิ่งหลัก) แต่ละกิ่งเป็นคำสำคัญสั้น ๆ ตามหลักของ Tony Buzan
  - ตัดแต่คำ ไม่แต่งเติม: ตัดคำฟุ่มเฟือยและคำที่กิ่งแม่พูดไปแล้ว เลือกช่วงที่มีตัวเลข และไม่ตัดคำปฏิเสธ (“ไม่ควร”) หรือหน่วยของตัวเลข
  - หัวข้อยาว ๆ แตกเป็นหัวข้อย่อยจากคำที่พูดซ้ำ · ✓ = ตกลงแล้ว · คือ … = นิยาม · ข้อดี/ข้อเสีย เป็นกิ่งย่อย
  - *ต้องทำ* แยกตามคน · *ยังไม่สรุป* · สัมภาษณ์: กิ่งละคำถาม คำตอบอยู่ใต้กิ่ง
  - แตะกิ่งในหน้าบันทึกเพื่อฟังช่วงนั้น (อย่าง Mapify)
  โน้ตยาว ๆ ก็ทำเป็นมายด์แมปได้ (แตะโน้ต → *ทำมายด์แมป*)
- **สรุปด้วย Claude** ก็ได้ถ้าต้องการ (คัดลอกและวางแบบเดียวกัน ไม่ต้องมีคีย์): ส่งข้อความที่ถอดพร้อมเวลา [นาที:วินาที] และช่วงที่ปักหมุด
  Claude ตอบเป็นหัวข้อ *ชื่อเรื่อง · สรุป · มายด์แมป · สิ่งที่ต้องทำ* วางกลับมาแล้วแอปใส่ให้ครบ (เลิกทำได้)
  เวลาในสรุปแตะเล่นได้ กิ่งที่มีเวลาแตะฟังช่วงนั้นได้เหมือนสรุปในเครื่อง · Claude ฟังไฟล์เสียงไม่ได้ จึงใช้ข้อความที่ถอดแล้ว
- **มายด์แมป** แบบ XMind/OPPO Notes: หัวข้อกลาง กิ่งสีซ้ายขวา เลื่อน/ซูมด้วยนิ้ว แตะเลือก แตะสองครั้งแก้ พับ/กาง ลบ
  คีย์บอร์ด: `Tab` กิ่งย่อย, `Enter` กิ่งข้างกัน, `F2` แก้, `Delete` ลบ, ลูกศรเลื่อนไปมา, `Alt+↑/↓` สลับลำดับ, `0` ดูทั้งหมด
  บันทึกเป็นรูป PNG, คัดลอก/วางเป็นโครงร่าง markdown (วางคำตอบทั้งก้อนจาก Claude ได้), ให้ Claude ขยายความ (คัดลอกและวาง), สร้างใหม่จากหัวข้อเดียวก็ได้
- **ค้นหาในข้อความที่ถอด**: พิมพ์คำแล้วไล่ดูทุกจุดที่พูดถึงพร้อมเวลา แตะเพื่อฟังจากตรงนั้น คำสำคัญจากสรุปเป็นชิปให้แตะค้นได้เลย
- มายด์แมปเลือกโครงได้: กิ่งสองข้าง หรือแตกไปทางขวาทั้งหมด (⋮ ในมายด์แมป)
- ข้อความ สรุป และมายด์แมปซิงก์ไปทุกเครื่อง ไฟล์เสียงอยู่ในเครื่องที่อัด (แชร์ไฟล์ได้จากเมนู ⋮)
- ในแอป Android ([แปะไว้ ที่ notch](../paewai-notch/)) อัดด้วยตัวอัดของเครื่อง อัดต่อได้แม้ปิดจอ เริ่มจากปุ่มแผงด่วนหรือปุ่มด้านข้างได้

## ทำอะไรได้

- **จัดให้อัตโนมัติ**: พิมพ์อะไรก็ได้ แปะไว้ดูให้ว่าเป็นอะไร (ในเครื่อง ไม่ใช้เน็ต) แตะป้ายก่อนกด Enter เพื่อเปลี่ยนเองได้
  - มีวัน/เวลา/ทำซ้ำ → **เตือน** · ขึ้นต้นด้วยการกระทำ (โทร ส่ง จอง…) → **งาน**
  - ไอเดีย รหัส เบอร์โทร ลิงก์ ร้าน → **โน้ตย่อ** (การ์ดแบบ Keep ปักหมุดได้)
  - `ซื้อนม ไข่ ขนมปัง` → **ของต้องซื้อ** แยกเป็นรายการและจัดตามแผนกในร้าน
  - `ข้าวมันไก่ 50`, `เติมน้ำมัน 1,200 บาท` → **รายจ่าย** พร้อมหมวด (หน้า เงิน: วันนี้ 7 วัน เดือนนี้ กราฟ และสัดส่วนหมวด)
- **เตือนซ้ำ**: `ทุกวัน 8 โมง กินยา`, `ทุกวันทำงาน`, `ทุกจันทร์`, `ทุกวันที่ 25`, `ทุกเดือน`, `3 มี.ค. ทุกปี` ติ๊กแล้วเลื่อนไปครั้งถัดไปเอง นับว่าทำไปกี่ครั้ง
- **ค้นหาทุกอย่าง**: งาน โน้ต บันทึกประจำวัน ของต้องซื้อ และรายจ่าย ในหน้า โน้ต
- **แปะเร็ว**: เปิดมาช่องพิมพ์พร้อม กด Enter แล้วพิมพ์เรื่องต่อไปได้ทันที วางข้อความหลายบรรทัด = หลายเรื่อง
- **วันเวลาภาษาพูด**: `พรุ่งนี้ 5 โมงเย็น โทรหาแม่`, `บ่ายสองครึ่ง`, `สองทุ่ม`, `ตี 5`, `ศุกร์นี้`, `จันทร์หน้า`,
  `สัปดาห์หน้า`, `อีก 20 นาที`, `อีก 3 วัน`, `วันที่ 25`, `15/11`, `3 ธ.ค. 69`, `17:30`, `17.30 น.` (เลขไทยก็ได้)
  ก่อนกด Enter จะเห็นป้ายวันเวลาที่อ่านได้ แตะ × ถ้าไม่อยากให้แปลง ไม่มีวัน = ลงกล่องรับ
- **กล่องรับ / วันนี้ / ข้างหน้า 6 วัน**: งานที่ค้างจากวันก่อนขึ้นในวันนี้พร้อมป้าย “ค้างจาก…” ยกมาทีเดียวได้
- **แตะเรื่อง** เพื่อแก้ ย้ายไปกล่องรับ/วันนี้/พรุ่งนี้/สัปดาห์หน้า ตั้งวันเวลา ลบ (มีเลิกทำ)
- **ลงปฏิทิน**: สร้างไฟล์ .ics ให้ Samsung Calendar (หรือปฏิทิน iPhone) เตือนตรงเวลาแม้ปิดแอป
- **เตือนในแอป**: ถึงเวลาแล้วมีเสียงและแจ้งเตือน ขณะแอปเปิดหรือย่อเป็นไอคอนลอยอยู่
  แจ้งเตือนมีปุ่ม **เลื่อน 10 นาที** และ **เสร็จแล้ว** (เลื่อนแล้วงานยังอยู่ที่เวลาเดิม เตือนซ้ำรายวันไม่เพี้ยน)
- **งบรายเดือน**: ตั้งงบในหน้า เงิน บอกว่าเหลือเท่าไร ใช้ได้อีกวันละเท่าไรถึงสิ้นเดือน (ใช้ร่วมกันทุกเครื่องที่ซิงก์)
- **โน้ตรายวัน**: เทความคิดยาว ๆ บรรทัดไหนเป็นงานกด “บรรทัดนี้ → งาน” (หรือ Ctrl+Enter)
- **โฟกัส**: จับเวลา 5/15/25/50 นาที พัก/ต่อ/+5 นาที สรุปเวลาโฟกัสและงานที่เสร็จ 7 วัน
- **พูดแทนพิมพ์** (Chrome, ต้องต่อเน็ต) · โหมดมืด · ใช้ออฟไลน์ได้ · สำรอง/กู้คืนเป็นไฟล์ · คัดลอกงานค้างไปวางในแชต
- **วางรายการจากที่อื่น**: วางข้อความหลายบรรทัดจาก LINE, Notes หรือคำตอบของ Claude ตัดหัวข้อ `##`, ตัวหนา, `- [ ]`, เลขข้อ ให้เอง
- **คีย์บอร์ด** (Book Cover Keyboard / DeX): `/` หรือ `Ctrl+K` ไปช่องแปะ, `Esc` ล้าง, `Ctrl+1`–`4` สลับหน้า

“ศุกร์หน้า / จันทร์หน้า” นับสัปดาห์เริ่มวันอาทิตย์แบบปฏิทินไทย (วันอาทิตย์ที่ 8 → ศุกร์นี้ = 13, ศุกร์หน้า = 20)

ข้อจำกัด: เว็บแอปตั้งปลุกตอนปิดแอปเองไม่ได้ จึงใช้ “ลงปฏิทิน” แทน (แอป Android [แปะไว้ ที่ notch](../paewai-notch/) ตั้งปลุกได้) ·
ข้อมูลอยู่ใน `localStorage` ของเครื่อง และใน repo GitHub ส่วนตัวถ้าเปิดซิงก์ (สำรองเป็นไฟล์ได้จากเมนู ⋮)

## พัฒนา

ไม่มี dependency ใช้แค่ Node 20+ (โค้ดภายนอกสองชิ้นถูก bundle ไว้แล้วใน `src/vendor/` ดู `LICENSES.txt`)

```bash
npm test        # ตัวอ่านวันเวลาไทย, ข้อมูล, ซิงก์, Claude, เสียง, สรุปในเครื่อง, มายด์แมป, ไฟล์ปฏิทิน, ผล build
npm run build   # src/ → dist/ พร้อมใส่รายการไฟล์และเวอร์ชันใน service worker
npm run dev     # build แล้วเปิดที่ http://localhost:4173/More-co./paewai/
npm run icons   # วาดไอคอน PNG ใหม่จาก SVG (ต้องมี Playwright)
```

อัปเดตโค้ดใน `src/vendor/` (ในโฟลเดอร์ชั่วคราว ไม่ใช่ใน repo):

```bash
npm i @anthropic-ai/sdk@<รุ่น> qrcode-generator@1.4.4 esbuild
echo "export { default as Anthropic } from '@anthropic-ai/sdk';" > a.js
echo "import q from 'qrcode-generator'; export default q;" > q.js
npx esbuild a.js --bundle --format=esm --minify --platform=browser --outfile=anthropic.js
npx esbuild q.js --bundle --format=esm --minify --platform=browser --outfile=qrcode.js
```

แล้วคัดลอกมาทับ โดยเก็บบรรทัดหัวไฟล์ (ชื่อ รุ่น และสัญญาอนุญาต) ไว้
