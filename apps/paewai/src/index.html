        วางโครงร่าง

        วางคำตอบจาก Claude หรือรายการหัวข้อ (# หัวข้อ - กิ่ง เยื้องเข้าเป็นกิ่งย่อย) จะแทนที่มายด์แมปนี้

        ให้แปะไว้อยู่ติดขอบจอ Samsungแปะไว้บน iPhoneแถบแปะไว้ที่ notch

        1. เปิดแถบที่ notch การตั้งค่า → การช่วยเหลือการเข้าถึง → แอปที่ติดตั้ง → แปะไว้ ที่ notch → เปิด
        2. ถ้ากดเปิดไม่ได้ ขึ้นว่า “การตั้งค่าที่ถูกจำกัด” เพราะติดตั้งเองไม่ผ่าน Play Store: เปิด ข้อมูลแอป → แตะ ⋮ มุมขวาบน → อนุญาตการตั้งค่าที่ถูกจำกัด แล้วกลับไปทำข้อ 1
        3. ใช้งาน แตะแถบดำรอบกล้อง หรือปัดลงจากแถบ = ช่องแปะเลื่อนลงมาทับแอปที่ใช้อยู่ พิมพ์ กด Enter แตะข้างนอกเพื่อเก็บ · กดค้างที่แถบ = เปิดแอปเต็ม · ตัวเลขบนแถบ = เรื่องที่ต้องทำวันนี้ ตอนโฟกัสจะเป็นเวลาที่เหลือ · ถึงเวลาเตือน แถบจะขยายบอก
        4. อัดเสียงได้ทันทีจากทุกที่ ปัดแผงด่วนลง → แก้ไข → ลากปุ่ม อัดเสียง เข้ามา (แตะ = เริ่ม แตะอีกครั้ง = หยุด) · ปุ่มด้านข้าง: การตั้งค่า → ฟีเจอร์ขั้นสูง → ปุ่มด้านข้าง → กดสองครั้ง → เปิดแอป → อัดเสียง แปะไว้ · อัดต่อได้แม้ปิดจอหรือใช้แอปอื่น แถบที่ notch เป็นจุดแดงพร้อมเวลา หยุดได้จากการแจ้งเตือน · ถอดเป็นข้อความไปพร้อมกัน ด้วยระบบรู้จำเสียงของแท็บเล็ต (ตัวเดียวกับพิมพ์ด้วยเสียง) ไม่ใช้ AI อื่น ไม่ต้องใช้คีย์ · อัดด้วยแอปบันทึกเสียงของ Samsung ก็ได้: แชร์ไฟล์เสียง → แปะไว้ (ถอดเป็นข้อความ) หรือแชร์ข้อความถอดเสียงของ Samsung มาที่แปะไว้ · เสร็จแล้วอยู่ใน โน้ต → บันทึกเสียง สรุปและทำมายด์แมปต่อได้

        ใช้สิทธิ์การช่วยเหลือการเข้าถึงเพียงเพื่อวางแถบทับแถบสถานะได้ แปะไว้ไม่อ่าน ไม่เก็บ และไม่ส่งสิ่งที่อยู่บนจอไปที่ไหน

        iPhone ไม่ให้แอปบนเว็บวางอะไรไว้ที่ Dynamic Island แต่ทำให้เรียกแปะไว้ได้ไวพอ ๆ กันด้วยหน้าจอโฮม ปุ่มลัด และการเคาะหลังเครื่อง

        1. เพิ่มลงหน้าจอโฮม เปิดหน้านี้ใน Safari → ปุ่มแชร์ ⬆︎ → เพิ่มไปยังหน้าจอโฮม → เปิดจากไอคอนนั้น (เต็มจอ ใช้ออฟไลน์ได้) ✓ เปิดจากหน้าจอโฮมแล้ว
        2. ซิงก์กับแท็บเล็ต ⋮ → ซิงก์ข้ามเครื่อง → วางโค้ดจากแท็บเล็ต (แท็บเล็ต: ⋮ → ซิงก์ข้ามเครื่อง → เชื่อมเครื่องอื่น)
        3. เคาะหลังเครื่อง 2 ครั้ง = พูดแล้วแปะ ทำคำสั่งลัด (Shortcuts) “แปะไว้” ที่ฟังเสียงแล้วส่งเข้าแปะไว้ทันทีโดยไม่ต้องเปิดแอป ดูขั้นตอนและค่าที่ต้องคัดลอกที่ ⋮ → ซิงก์ข้ามเครื่อง → คำสั่งลัด iPhone แล้วไปที่ การตั้งค่า → การช่วยการเข้าถึง → สัมผัส → แตะด้านหลัง → แตะสองครั้ง → เลือก “แปะไว้” · เรียกด้วย “หวัดดี Siri แปะไว้” หรือใส่เป็นปุ่มบนหน้าจอล็อกก็ได้

        เตือนตามเวลา: iPhone เด้งเตือนได้ตอนเปิดแอปอยู่ ถ้าต้องการให้ดังแม้ปิดแอป แตะเรื่องนั้น → ลงปฏิทิน ปฏิทินของ iPhone จะเตือนให้

        บน MacBook มีรอยบากให้เรียกแอปจด บนแท็บเล็ต Samsung ใช้ขอบจอ (Edge panel) กับหน้าต่างลอย (Pop-up view) แทน ตั้งครั้งเดียว ใช้ได้ตลอด

        มี Galaxy Tab S Ultra ที่มี notch? แปะไว้ฉบับแอป Android มีแถบครอบกล้องด้านบน แตะแล้วช่องแปะเลื่อนลงมาจาก notch

        1. ติดตั้งเป็นแอป เปิดหน้านี้ใน Chrome → ⋮ → เพิ่มลงในหน้าจอหลัก หรือ ติดตั้งแอป (Samsung Internet: ≡ → เพิ่มหน้าลงใน → หน้าจอหลัก) ✓ เปิดจากแอปที่ติดตั้งแล้ว
        2. ใส่ไว้ใน Edge panel การตั้งค่า → หน้าจอ → Edge panels → เปิด → แตะแผง แอป → แก้ไข → เพิ่ม แปะไว้
        3. เปิดเป็นหน้าต่างลอย ปัดแถบเล็ก ๆ ที่ขอบจอเข้ามา แล้วลากไอคอน แปะไว้ ออกมาวางกลางจอ จะเปิดเป็นหน้าต่างลอยทับแอปที่ใช้อยู่ (ลากจากแถบงาน/Taskbar ด้านล่างก็ได้)
        4. ย่อเป็นไอคอนลอย แตะแถบด้านบนของหน้าต่างลอย → ปุ่ม ย่อ จะกลายเป็นวงกลมเล็ก ๆ ลอยอยู่ข้างจอ นึกอะไรออกก็แตะ พิมพ์ กด Enter แล้วย่อกลับ
        5. ทางลัดอื่น ๆ กดค้างที่ไอคอนแอป → แปะเรื่องใหม่ / โน้ตวันนี้ / โฟกัส 25 นาที (ลากทางลัดไปวางบนหน้าจอหลักได้) · แชร์ข้อความหรือลิงก์จากแอปไหนก็ได้ → เลือก แปะไว้ จะเข้ากล่องรับ
