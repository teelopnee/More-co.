ติดตั้ง

  1. ดาวน์โหลด เปิดหน้านี้บนแท็บเล็ต แตะปุ่มด้านบน ถ้า Chrome เตือนว่าไฟล์อาจเป็นอันตราย แตะ ดาวน์โหลดต่อ
  2. ติดตั้ง แตะไฟล์ที่ดาวน์โหลดเสร็จ → การตั้งค่า → อนุญาตให้ Chrome ติดตั้งแอป → กลับมาแตะ ติดตั้ง
  3. เปิดแถบที่ notch เปิดแอป แปะไว้ → ⋯ → ตั้งค่าแถบที่ notch → ไปที่หน้าตั้งค่า → การช่วยเหลือการเข้าถึง → แอปที่ติดตั้ง → แปะไว้ ที่ notch → เปิด
  4. ถ้าสวิตช์กดไม่ได้ ขึ้นว่า “การตั้งค่าที่ถูกจำกัด” การตั้งค่า → แอป → แปะไว้ → ⋮ มุมขวาบน → อนุญาตการตั้งค่าที่ถูกจำกัด แล้วทำข้อ 3 อีกครั้ง
ถ้าติดตั้งไม่ได้ ขึ้นว่าแอปถูกบล็อก

Google Play Protect และ Samsung Auto Blocker บล็อกแอปที่ติดตั้งเองแล้วขอสิทธิ์การช่วยเหลือการเข้าถึง เพื่อกันแอปมิจฉาชีพ ถ้าเจอ ให้ปิดชั่วคราวเฉพาะตอนติดตั้งไฟล์จากหน้านี้ แล้วเปิดกลับทันที:

Play Store → รูปโปรไฟล์ → Play Protect → ⚙ → ปิด สแกนแอปด้วย Play Protect
การตั้งค่า → ความปลอดภัยและความเป็นส่วนตัว → Auto Blocker → ปิด

อย่าทำแบบนี้กับไฟล์ APK ที่ได้มาจากที่อื่น

ทำไมต้องขอสิทธิ์การช่วยเหลือการเข้าถึง

Android ให้แอปวางอะไรทับแถบสถานะ (ตรง notch) ได้เฉพาะผ่านสิทธิ์นี้ แปะไว้ใช้แค่เพื่อวางแถบ ไม่อ่าน ไม่เก็บ และไม่ส่งสิ่งที่อยู่บนจอไปที่ไหน (ตั้งค่า canRetrieveWindowContent="false" ไว้) งานทั้งหมดเก็บในเครื่องนี้เท่านั้น

รู้ไว้

  • ข้อมูลในแอปนี้แยกจาก แปะไว้ฉบับเว็บ ย้ายได้ด้วย ⋯ → สำรองข้อมูล แล้ว กู้คืน ในอีกฝั่ง
  • ดูวิดีโอหรือเล่นเกมเต็มจอ แถบจะพยายามหลบให้ (ปิดได้ในหน้าตั้งค่าแถบ)
  • กดค้างที่แถบ = เปิดแอปเต็ม (โน้ต โฟกัส สัปดาห์ข้างหน้า) · แชร์ข้อความจากแอปอื่นมาที่ แปะไว้ ได้
