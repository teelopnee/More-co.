# จดไว — จดรายรับรายจ่ายจากสลิป

เว็บแอป (PWA) สำหรับจดรายรับรายจ่ายส่วนตัว แค่เลือกรูปสลิปโอนเงิน แอปจะอ่านยอดเงิน วันที่ เวลา ชื่อผู้รับ/ผู้โอน เลขอ้างอิง และบันทึกช่วยจำให้เอง
**ทุกอย่างทำในเครื่อง** ไม่ส่งรูปหรือข้อมูลการเงินออกไปไหน ไม่มีบัญชีผู้ใช้

ใช้ได้ทั้ง iPhone, Android และแท็บเล็ต ติดตั้งลงหน้าจอหลักแล้วใช้แบบออฟไลน์ได้

## ความสามารถ

- **สแกนสลิปทีละหลายรูป** — อ่านด้วย OCR ภาษาไทย+อังกฤษ (Tesseract) ในเครื่อง รองรับรูปแบบวันที่ไทย (3 พ.ย. 69, 03 พ.ย. 2569, 2 พฤศจิกายน 2569) และอังกฤษ
- **กันบันทึกซ้ำ** — อ่าน QR บนสลิป (เลขอ้างอิงธุรกรรม) ถ้าเคยบันทึกแล้วจะไม่บันทึกซ้ำ
- **รู้ว่าเป็นเงินเข้าหรือออก** — ใส่ชื่อตัวเองในหน้าตั้งค่า สลิปที่โอนมาหาเราจะเป็นรายรับอัตโนมัติ
- **เดาหมวดหมู่ให้** — จากชื่อร้าน/บันทึกช่วยจำ และ **จำ** ว่าผู้รับคนนี้เราเคยเลือกหมวดอะไร
- **แชร์รูปจากแกลเลอรีเข้าแอป** (Android, หลังติดตั้ง)
- สรุปรายเดือน, กราฟรายจ่ายรายวัน, แยกตามหมวดหมู่, เทียบกับเดือนก่อน
- จดเอง แก้ไข ลบ (มีปุ่มเลิกทำ)
- สำรอง/กู้คืนข้อมูล (รวมข้อมูลจากหลายเครื่องได้), ส่งออก Excel (CSV)
- โหมดมืด, รองรับมือถือและแท็บเล็ตจอใหญ่

## พัฒนา

```bash
npm install          # ติดตั้ง + คัดลอกไฟล์ OCR ไปที่ public/ocr
npm run dev          # เปิดเซิร์ฟเวอร์ทดสอบ
npm test             # unit test + ทดสอบ OCR กับสลิปตัวอย่างจริง
npm run build        # สร้างไฟล์สำหรับเผยแพร่ใน dist/
npm run e2e          # ทดสอบทั้งแอปใน Chromium (ต้องมี Playwright, รัน build ก่อน)
```

สคริปต์อื่น ๆ (ต้องมี Playwright):

- `node scripts/make-test-slips.mjs` — สร้างสลิปตัวอย่างสำหรับทดสอบใน `tests/fixtures/slips`
- `node scripts/make-icons.mjs` — สร้างไอคอนแอปใน `public/icons`

## โครงสร้าง

| ส่วน | ไฟล์ |
|---|---|
| อ่านสลิป (OCR + QR → ข้อมูล) | `src/slip/` — `parse.ts` ตัวแยกข้อมูล, `thaiDate.ts` วันที่ไทย, `qr.ts` QR สลิป, `reader.ts` ฝั่งเบราว์เซอร์ |
| ฐานข้อมูลในเครื่อง (IndexedDB) | `src/lib/db.ts`, `src/lib/actions.ts` |
| หมวดหมู่ + เดาหมวดอัตโนมัติ | `src/lib/categories.ts` |
| หน้าจอ | `src/pages/` (รายการ, ตรวจสลิป, สรุป, ตั้งค่า) |
| Service worker (ออฟไลน์ + แชร์รูปเข้าแอป) | `src/sw.ts` |

## เผยแพร่

GitHub Actions (`.github/workflows/deploy.yml`) จะรันเทสต์และ build ทุกครั้งที่ push
และเผยแพร่ขึ้น GitHub Pages จาก branch หลักของ repo
ต้องเปิดครั้งแรกที่ **Settings → Pages → Source: GitHub Actions**

## ข้อจำกัดที่รู้อยู่

- ชื่อคนภาษาไทยบางชื่ออาจอ่านผิดบ้าง (ยอดเงินและวันที่แม่นกว่า) แก้ได้ในหน้าตรวจสลิปก่อนบันทึก
- ข้อมูลแยกตามเครื่อง ใช้ "สำรองข้อมูล" แล้ว "กู้คืน" เพื่อย้าย/รวมข้อมูลระหว่างเครื่อง
- บน iPhone ควรติดตั้งลงหน้าจอโฮม เพื่อไม่ให้ Safari ลบข้อมูลเมื่อไม่ได้เปิดนาน ๆ และควรสำรองข้อมูลเป็นระยะ

# ศึกอัสนี — เกมต่อสู้ 3D (`game/`)

เกมต่อสู้ 1 ต่อ 1 บนวิหารลอยฟ้ากลางพายุ เล่นในเบราว์เซอร์ (WebGL2 + Three.js) ไม่มีไฟล์รูปหรือเสียงเลยสักไฟล์
ทุกอย่างสร้างด้วยโค้ด: ตัวละคร ฉาก แสง เอฟเฟกต์ และเพลง (สังเคราะห์สดด้วย Web Audio มีทำนองแบบระนาดเอก)
เผยแพร่คู่กับแอปหลักที่ `/game/` บน GitHub Pages

## เล่นยังไง

- **เล่นกับคอม** (ง่าย/ปกติ/โหด), **สองผู้เล่น** (คีย์บอร์ดเดียวกันหรือจอย 2 ตัว), **ฝึกซ้อม** (เลือดไม่ลด เกจเต็มตลอด)
- คีย์บอร์ด P1: `WASD` เดิน/กระโดด/ย่อ, `J` หมัด, `K` เตะ, `L` พลัง, `I` ไม้ตาย · P2: ลูกศร, `,` `.` `/` และ `Shift ขวา` (หรือ Numpad 1/2/3/0)
- รองรับจอยเกม (Xbox/PlayStation) และจอสัมผัส (จอยสติ๊กซ้าย ปุ่มขวา) · `Esc` หยุดเกม
- ถอยหลังค้าง = ป้องกัน, ย่อ+ถอย = กันท่าต่ำ, กดเดินหน้า/ถอยสองครั้ง = พุ่งตัว
- ท่าปกติที่โดนแล้วยกเลิกเข้าท่าพลังหรือไม้ตายได้ ต่อคอมโบยาว ๆ ได้ (มีการลดดาเมจตามจำนวนฮิต)

นักรบ 3 คน: **วายุ** (สายฟ้า เร็ว), **เพลิง** (ไฟ หนัก ทน), **จันทรา** (จันทร์ สมดุล ลูกพลังเร็ว)
แต่ละคนมีลูกพลัง ท่าพุ่ง ท่าทะยานฟ้า และไม้ตายลำแสง 10 ฮิตพร้อมฉากซูมกล้อง

## กราฟิก

พื้นหินเปียกสะท้อนแบบกระจกจริง (planar reflection) + ระลอกฝน, bloom แบบ HDR, god rays จากดวงจันทร์,
ฝนหลายพันเส้น, ฟ้าผ่าพร้อมฟ้าร้องตามระยะ, โคมลอย, อนุภาคประกายไฟหลายหมื่น, เงา, ภาพติดตาตอนพุ่ง, ผ้าพันคอจำลองฟิสิกส์,
กล้องสั่น/ซูมตามแรงกระแทก, slow motion ตอน K.O.

คุณภาพมี 5 ระดับ (สุดขีด → ต่ำ) โหมด **อัตโนมัติ** เริ่มที่ระดับสูงสุดที่เหมาะกับอุปกรณ์ แล้วลดระดับเองถ้าเฟรมเรตต่ำกว่า ~50 FPS
เปิดดู FPS ได้ในหน้าตั้งค่า หรือบังคับระดับผ่าน URL เช่น `?quality=ultra`

## พัฒนา

```bash
npm run dev:game     # เปิดเกมที่ http://localhost:5174
npm run build:game   # build เกมไปที่ dist/game (npm run build ทำให้ทั้งแอปหลักและเกม)
```

`/poses.html?char=vayu` (เฉพาะตอน dev) แสดงท่าทางทั้งหมดของตัวละครไว้ปรับท่า

| ตัวละคร | `game/src/data/characters.ts`, `game/src/fighter/` (โครงกระดูก ท่าทาง การขยับ) |
| ฉากและการเรนเดอร์ | `game/src/render/` — `engine.ts` post-processing + เงาสะท้อน, `stage.ts` ฉาก, `quality.ts` ระดับกราฟิก |
| เอฟเฟกต์ | `game/src/fx/` |
| กล้องและจังหวะภาพ | `game/src/director.ts` |
| เสียงและเพลง | `game/src/audio/audio.ts` |
| หน้าจอ HUD เมนู | `game/src/ui/`, `game/src/styles.css` |
| เทสต์ระบบต่อสู้ | `tests/unit/game-fight.test.ts` |
